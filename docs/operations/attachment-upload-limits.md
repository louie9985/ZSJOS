# 中世健附件上传大小

通用业务附件的默认单文件上限为 **100 MB**，按 100 × 1024 × 1024 = 104857600 字节计算；恰好达到上限允许，超过上限拒绝。

适用范围：公告、客资附件及 H5 图片附件、销售反馈、订单凭证、报名材料、学员联系附件、提现凭证、考期附件、定位卡/访谈/确认凭证、媒体账号资料，以及管理端通用文件上传、审批操作和人事附件。数量、格式、文件头、租户及归属校验保持原规则。

表单设计器新建附件字段默认 100 MB。管理员已经配置并保存的 BPM、强制表单、素材字段仍按对应字段配置校验；修改已发布表单需经过该表单正常编辑/发布流程，不自动改写历史快照。素材字段已有默认值为 100 MB。

头像、正文内图片、Excel/素材导入属于各自专用规则；生产内容视频及直传通道已有更大上限，继续保留。此次未降低这些通道的容量，也不以通用附件限制替代其业务校验。

管理端、工作台及 H5 的 multipart 上传给予至少 10 分钟客户端等待时间，普通 JSON 请求超时不变；显式无限或更长上传超时保留。管理端上传助手支持 Axios 在拦截器之后转换为 multipart 的普通对象参数。

后端 `backend/yudao-server/src/main/resources/application.yaml` 已设置单文件 1024 MB、整请求 2048 MB，可容纳 100 MB 附件，不需降低全局容量。业务服务负责本功能的 100 MB 校验。

部署时必须检查实际反向代理和存储限制。仓库未提供可确认覆盖部署的 Nginx 请求体配置；若使用 Nginx，单文件请求需给 multipart 边界留余量，例如 `client_max_body_size 110m;`，并检查上传/读取超时。多文件单请求应按实际合计体积另行计算。部署配置可能覆盖 Spring 默认配置，应以目标运行环境为准。源码修改不代表已部署生效；此次不重启或修改共享服务。

## 工单上传内存边界（2026-10-14）

`POST /admin-api/zsjos/work-order/file/upload` 在打开文件流前拒绝空文件及超过 100MB 的文件。进程内默认最多同时处理 2 个请求，已接收请求申报文件大小的合计预算为 100MB；预算不足立即返回“工单附件上传繁忙，请稍后重试”，不排队、不自动重试。单个恰好 100MB 的请求可独占预算；两个 50MB 请求可并行。

实现一次分配申报大小的字节数组，有界读取并验证实际流长度；保留原 `byte[]` 存储接口。预算从读流前一直持有到存储调用结束，打开、读取、关闭、存储失败或异常退出均释放。此预算约束该入口的应用缓冲区，并非 JVM 总堆上限；Servlet multipart 暂存、存储 SDK 和其他请求仍有独立内存开销。

局部配置前缀为 `zsjos.work-order.upload`：`max-concurrent-requests` 默认 2（允许 1–2），`max-in-flight-bytes` 默认 104857600（允许 1–104857600）。可按环境收紧预算；低于单文件大小时会返回繁忙。配置不变更业务单文件 100MB 上限，不降低全局上传容量。配置值是源码默认值，目标服务须正常部署后核对实际生效值。

Workbench 工单选择文件与剪贴板上传共用服务端点及读前大小校验，并显示 100MB 和繁忙重试提示。Admin 当前只有工单模板与审计页面，没有该上传端点的消费者；本次不新增员工上传页面。

## 文件存储与 Excel 故障提示

缺少默认文件存储时返回业务错误 `1001006002`（“尚未配置默认文件存储，请联系管理员设置”）；默认配置存在但客户端未能提供时返回 `1001006003`（“默认文件存储不可用，请联系管理员检查配置”）。配置加载失败不缓存成功值，管理员修正配置后可重试；本次未创建或修改真实存储配置。

Excel 模板遇到空字典时不生成非法的零行下拉范围，其他字典下拉保持可用。地区列使用既有权威区域数据输出可重新导入的 `/` 分隔路径；空值写空单元格，无效地区编号明确拒绝写出，不编造地区名称。资产导出保留非空附件列表按换行文本输出的回归覆盖。
