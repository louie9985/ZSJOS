# 报名提前交付

报名审核通过后，保存分班即建立当前商品的交付服务；学习规划师可接收并正常履约。
财务待审核不阻塞流转，财务通过及资料齐备仍是人工完成报名任务的前置条件。
正式班通知班主任，待分班无负责人。首次分班一经流转即保留快照，改班使用班级管理。
同一学员的其他产品独立处理。已有服务完成报名时保持服务 ID、接收状态及交付历史。

## 异常与历史

- 财务驳回或审批异常终止：报名任务保留待处理，停止该订单提前交付及未完成待办；不删除已发生记录。
- 结束本产品：停止当前报名任务服务及未完成待办，保留同订单兄弟产品；必须填写原因。
- 主动终止及接续重提：取消旧订单服务；新订单重新审核、分班，不迁移旧服务事实。
- 历史已保存但未交付：人员再次保存触发交付。终态任务不重放，不自动批量回填。
- 学生身份更新提前到实际建立服务；订单生效、资金及业绩规则不变。

## 验收

真实目标环境应验证：财务待审订单 → 保存分班 → 指定学习规划师看到对应服务并接收 → 财务通过 → 人工完成。
另验财务驳回和结束产品的服务/待办关闭、通知送达，转班后完成及重复请求幂等。
服务列表、报名详情显示审核状态和当前交付班级。首次班级快照不因转班重写。

本地 Java 和浏览器 fixture 只证明源码及模拟接口行为，不代表部署、登录态或消息规则已送达。
Workbench 当前 390px 报名页沿用仅产品列表展示，详情操作未作为本次移动端交付范围；Admin 抽屉支持窄屏操作。
