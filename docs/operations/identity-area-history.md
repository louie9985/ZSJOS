# 身份证地址码历史资料

资料位于 `script/sql/mysql/data/identity-area/`，固定来源提交、CC0 许可和 SHA-256 在 `source.json`、`LICENSE` 中。原始 CSV 共 6,824 条行政区划记录，V362 导入其中 6,246 条县级记录，覆盖 5,893 个不同县级代码；340 个代码有多个历史记录，428 条记录有多个后继代码。覆盖 1981–2025 年，不承诺是完整公安赋码名录。

`python script/sql/mysql/tools/identity_area_data.py` 校验源文件摘要、列结构、重复记录和 UTF-8，并输出覆盖统计。不得在运行时访问外部数据源，更新资料须审核来源、差异及历史歧义，不能将后继代码当作人员当前户籍。

## 应用与恢复

依赖 V361 在两个版本表中存在。按标准迁移工具执行 V362，之后发布配套后端及 H5；执行前核对应用实际 JDBC 目标和迁移目标一致。该迁移只新增 `system_identity_area`、收集值的可空 `identity_area_snapshot` 列及基础资料，不改 `system_area`、权限分配或已有收集行。

DDL 可能隐式提交。失败不会写成功版本；修复原因后重跑可补齐部分结构。固定资料 ID 内容冲突直接失败，不覆盖人工改动。重复执行验证所有导入字段和记录数。应用回退时保留新增表列与资料，不删除已提交快照。已应用迁移更新遵循仓库迁移兼容规则。

`verify_identity_area.py` 使用 application-local 中的连接，创建独立验证库并保留，验证前置失败、DDL 后中断、恢复、重复执行、版本表和中文 HEX。仅可在明确授权的本地目标执行；不删除库或业务数据。

正常识别返回历史归属快照；多名称歧义、未收录或查询故障允许本人填写，均不能等同于身份证真实性核验。既有档案不自动改写。
