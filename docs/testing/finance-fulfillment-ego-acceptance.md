全新运行时启动仍有独立问题。业务 SQL 全链初始化后，应用启动在 Flowable 处理旧结构时遇到重复的 ACT_RU_TASK.SCOPE_ID_。隔离验收将 45 张 ACT_/FLW_ 表迁至保留库。JDBC 未限定当前 catalog 时仍从保留库读到元数据，报当前库缺 ACT_GE_PROPERTY。加 nullCatalogMeansCurrent=true 后，Flowable 8 在隔离业务库重新创建引擎表并成功启动。这套处理仅用于隔离验收。默认部署路径与保留存量流程的升级路径仍需分别验证。
