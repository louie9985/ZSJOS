# Workbench 收件箱滚动加载覆盖（2026-11-02）

主从收件箱滚动接近底部后读取下一批并追加，按业务主键去重。筛选改变或刷新第一页会清除旧批次，追加加载不自动切换已选详情。错误停止自动请求，保留已加载记录并重试失败页。表格仍使用分页。共享实现为 `InboxLoadMore` 和 `useInboxPageMerge`，既有游标实现不强行替换。

| 页面/入口 | 处理 |
| --- | --- |
| 报名资料收集 | 页码 API 滚动追加；表格分页 |
| 报名履约公共池 | 页码 API 滚动追加；追加不重新加载详情，不触发放弃未保存内容 |
| 我的学员/学员管理 | 按 serviceRelationId 追加；表格分页；追加不触碰档案编辑状态 |
| 客资投诉 | 页码 API 滚动追加；表格分页 |
| 下属兼职 | 页码 API 滚动追加；表格分页 |
| 内容生产、内容审核、旧媒体功能收件箱 | 页码 API 滚动追加；内容审核 URL 选择变化不重置已加载队列 |
| 拍摄工单的待接收/我的工单收件箱 | 页码 API 滚动追加；抢单卡片网格不是收件箱，保留原分页 |
| 公海池 | 原追加 API 接入自动滚动触发；表格分页 |
| 教务团队 | 原追加 API 接入自动滚动触发 |
| 工作计划左侧计划列表 | 页码 API 滚动追加；普通任务列表保留原分页 |
| 人员管理、我的运营成员导航 | 权威接口仍返回完整目录，界面按 20 条渐进呈现；不声称服务端分页或减少网络读取量 |
| 客资管理及复用它的子页面、申诉、重复审核 | 已有滚动/游标追加，保留 |
| 我的订单、订单审批、主管加签收件箱 | 已有滚动/游标追加，保留 |
| BPM 审批中心、消息、公告 | 已有滚动/游标追加，保留 |
| 媒体学员、下属销售、班级分组根列表 | 已有滚动追加，保留；展开班级组内的小班读取是独立子资源，不改为根队列 |

普通业务表格、抢单卡片网格、日历、首页任务卡、详情内联系记录及材料选择器不是收件箱，本次不替换其分页/完整目录协议。

验证入口：`npm test -- src/services/inboxAppend.test.ts`。合成浏览器数据覆盖真实 StudentInfoTasksPage（`test/order-collection.tsx?lazy&fail`）及 RegistrationPoolPage（`test/inbox-registration-lazy.tsx`）；应验证单页 20 条、失败重试、不重复请求、筛选重置、保留详情和表格分页。真实账号/生产数据验收与夹具验证分开记录。
