# 内容审核表单交互设计

## 目标

提升内容审核草稿编辑表单的可填写性，避免误关闭丢失数据，并让字典字段和参考作品选择符合服务端数据契约。

## 设计

- 编辑表单 Modal 使用更宽的桌面宽度并在小屏自适应，内容区可滚动。
- 图片上传成功后保存文件 ID 和预览地址，显示缩略图并支持放大查看。
- 发布平台、当前期段、账号状态、作品目的、作品形式均使用服务端字典选项，并保存值与标签快照。
- 参考作品使用二级 Modal 卡片选择器，支持搜索、分页、封面及作品元信息展示、确认和清除；主表单显示已选摘要。
- 编辑表单和参考作品选择器均禁用点击遮罩关闭，减少误操作导致的数据丢失。

## 验证

运行 Workbench typecheck、production build，并检查桌面和窄屏 Modal 布局及图片预览。
