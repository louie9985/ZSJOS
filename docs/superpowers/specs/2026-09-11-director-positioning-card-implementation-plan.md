# 编导定位卡调整实现计划

## 实现顺序

1. **模板与字段模型**
   - 扩展定位卡模板字段校验与配置 VO，支持普通字段新增、文本/附件/字典多选、提示、排序、必填、数量提示和素材选择配置。
   - 为素材关联规则定义稳定 JSON 结构：素材类型、默认筛选、是否可调整、推荐数量。
   - 保持已发布模板不可变，复制草稿后发布新版本。

2. **字典与初始化**
   - 新增 zsjos_director_content_form 字典类型及22条预置数据，使用 UTF-8/utf8mb4 SQL。
   - 更新定位卡默认模板：截图全部字段按顺序初始化；账号定位、人设类型；专业定位、素材适配专业方向；主要内容形式、新字典；采访稿全文、附件。
   - 字典维护沿用系统可配置菜单/按钮权限，不新增固定角色或审批流程。

3. **素材查询与引用**
   - 复用素材库分页查询和权限校验，增加定位卡选择器所需的素材类型、平台、适用阶段、账号定位、专业定位筛选。
   - 提供定位卡草稿素材关联的新增、移除和预览能力，绑定具体素材版本。
   - 默认筛选由模板返回，前端可清空或调整；提交不校验推荐数量。
   - 正式提交时冻结素材版本、展示标签和关键元数据，历史版本只读。

4. **定位卡提交与历史版本**
   - 草稿保存继续更新当前草稿，不创建历史版本。
   - 正式提交创建不可变版本，保存模板字段、字典标签快照、素材版本引用和附件元数据。
   - 增加历史版本查询和查看接口，按提交时快照渲染；历史定位、采访记录读取现有系统记录。
   - 采访稿全文仅接入附件上传、预览和下载。

5. **Workbench 页面**
   - 将现有定位卡表单改为访谈表单同款逐行布局，移动端纵向排列。
   - 按字段类型渲染文本、字典多选、附件和素材选择按钮。
   - 实现素材选择弹窗：默认筛选展示、筛选可调整、搜索、预览、多选、追加、移除、空/错/无权状态。
   - 展示平台和 S1-S6 推荐数量提示，但不阻止提交。
   - 增加历史版本入口和只读查看。

6. **后台配置页面**
   - 扩展定位卡模板配置页，支持字段新增、编辑、排序、启停、必填、提示、类型、字典和素材规则配置。
   - 按服务端权限显示查询、修改、发布入口；后端同步校验。

## 验证计划

- 后端：定位卡服务、模板服务、素材查询/引用服务单元测试；模板发布、字典快照、版本不可变和权限测试。
- SQL：UTF-8 语法、重复执行、空库初始化和字典数量/标签校验；代表性中文执行 HEX 检查。
- Workbench：
pm test、
pm run typecheck、
pm run build。
- 浏览器：桌面与移动宽度验证逐行布局、素材弹窗筛选、上传失败重试、空/错误/无权限、历史版本只读。
- 真实接口：验证三个字典、素材类型/平台/阶段筛选和正式提交快照。

## 风险与边界

- 不改现有访谈定位表单业务语义。
- 不新增字典审批流程、自动数据采集、周期提醒或字段级可见性。
- 不绑定“总监”角色，所有维护权限由服务端菜单/按钮配置。
- 已部署环境若存在已应用基线，需另行使用兼容 migration；不得重写已部署历史脚本。
