# 中世健首页动态指标

状态：用户确认需求；实施中，非上线说明。

## 已确认范围

系统管理维护指标名称、说明、单位、排序、数据来源、高级筛选、点击行为、可见范围；草稿、预览、发布、停用、复制、回退及并发冲突提示。Vue Admin 管理配置，React Workbench 展示指标；权限来自 System，业务行为归 ZSJOS。

客资筛选默认按客资主键去重计数；订单按订单主键；学员按所选业务视图的学员身份键去重，不能按课程服务条数计数。学员身份键必须在适配实际查询时明确，不擅自合并不同档案。

完整运算含计数/去重计数、数值字段 SUM/AVG/MIN/MAX、括号和加减乘除、比率、跨来源聚合值计算、同比和环比。除零显示无法计算；任何参与操作数无权限，整项不得返回数值。禁用任意 SQL、JavaScript、SpEL 或反射表达式执行。

## 数据来源和统计

后端注册业务视图能力，每个来源声明场景、计数身份键、允许聚合字段/单位、授权检查、基础查询、明细投影、受控路由。高级筛选服务负责合法条件，所属业务服务负责数据可见范围；不能将 filter match IDs 当成授权结果。

统计集合 = 当前查看者可读集合 ∩ 来源基础视图 ∩ 指标条件。当前用户/部门在读取时绑定。配置权限不赋予统计数据读取权限；预览使用操作者本人身份。租户仅 1，不提供租户选择器，仍保留既有租户上下文。

聚合必须先以业务身份键消除关联展开再计算。SUM/AVG/MIN/MAX 仅作用于来源登记的合法数值字段；金额使用 BigDecimal。空集 COUNT 为 0，SUM 为 0，AVG/MIN/MAX 返回 EMPTY；未知/无权限/失败不转换为 0。不得分页拉取全表到应用内聚合。

每个公式使用具名操作数，操作数包含 source/view、高级筛选、聚合、字段、时间定义。公式保存结构化 AST，展示为可读公式；括号由树结构表达。变量引用限本指标内操作数，不允许跨指标循环引用。限制深度、节点数、操作数数量、数字长度和查询成本。

单位验证：加减要求兼容单位；除法生成比率或复合单位；百分比仅是格式，不重复乘 100。显示小数位与计算精度分开，计算最终格式化前不逐步截断。负值合法；溢出、除零、空集、源错误分别返回状态。

## 时间和比较

统一 Asia/Shanghai；区间左闭右开。支持明确日期范围和相对自然周期，冻结本次查询实际起止时间。同比/环比比较同一来源、条件、范围语义和聚合方式；比较期的日期边界也返回客户端。

完整自然周期与截至当前时刻的可比周期需要在配置中明确，不能混用。同比按日历减一年，闰日使用 Java 日历规则并在预览标注；环比按对应周期回退。任意日期区间环比用前一个等长度区间。增长率 (本期-比较期)/比较期；比较期为零不可计算，不显示 100%。

## 点击和深链

单来源指标进入同口径分页明细；公式指标先展示公式及操作数，再进入某操作数明细。每个操作数独立选择与来源兼容的弹窗或路由。无唯一明细集合时不能宣称明细总数等于公式值。

查询上下文引用指标 ID、发布版本、查看者、已解析时间范围，服务端校验有效期和当前权限。URL 不包含敏感筛选值；不接受任意路由/外部地址。服务端能力目录加前端受支持目标注册表决定可用目标。直接访问和刷新都重新授权。

指标条件是不可被个人历史筛选覆盖的基础条件；追加筛选只能缩小。切换普通列表需要明确退出指标模式。数据更新可以使后来明细变化，显示统计时间与变化提示，不承诺查询间数据快照一致。

## 配置和权限

配置管理读取/新增/修改/发布/停用等操作使用 System 菜单按钮权限。每指标关联可配置查看权限，人员/组织限制作为额外交集，不能扩大业务授权。角色菜单授权只能在角色管理完成，迁移不写 system_role_menu。

配置主体保存稳定编码及草稿修订，发布版本不可变。乐观锁检查必须体现在更新 WHERE 条件，不只读后比较。发布事务写入版本并切换当前版本；回退生成新发布版本且重新校验。停用后旧查询上下文立即失效。

业务字典存 value/label 快照；历史标签不随字典改名改变。选项失效、来源或字段下线必须拒绝执行，不能忽略条件。执行时与发布时都校验。

## 可靠性和验证

卡片独立状态和重试，区分正常零、EMPTY、FORBIDDEN、INVALID_CONFIG、DIVIDE_BY_ZERO、SOURCE_ERROR、TIMEOUT。返回用户可理解错误，不暴露 SQL/敏感参数。

先测查询代价再决定缓存；缓存按用户授权上下文、配置版本、来源条件、实际时间区间分区，命中仍检查权限。批量首页查询限制并发和时间预算，单指标失败不影响其余项。

验收覆盖每来源允许/拒绝范围、重复关联去重、学员多服务、金额精度、嵌套公式、除零/空集/缺变量、跨来源权限、午夜/闰年/比较期、配置并发发布/回退、旧链接失效、前端异常及响应式展示、SQL 首次/重复/部分失败恢复。静态检查不替代数据库和浏览器验证。
