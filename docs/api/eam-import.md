# EAM V3 分类配置与资产台账导入

资产台账只读取工作表 `资产台账`。第 1 行是单层表头，第 2 行开始是资产数据；其他说明工作表不会创建资产。

分类配置模板包含 `分类`、`字段` 两张表。分类按分类编码幂等新增或更新，字段按“所属分类编码 + 字段标识”幂等新增或更新；模板缺失内容不会自动删除数据库记录。

台账主表按表头名称定位，列顺序可以调整；自定义字段表头使用 `字段标识:字段名称`，导入后以字段标识保存。必填业务列为 `分类编码`、`资产名称`。分类编码不存在、分类编码为空、资产名称为空或标准数字/日期格式错误，会进入预检错误并阻止提交。

资产编号为空时由分类编号规则生成；已有资产编号默认跳过，只有显式开启更新才更新。单件分类数量固定为 1；批量分类数量必须为正整数。使用人通过 System 用户 API 匹配，未匹配或重名只产生明确警告并保留姓名快照。

下拉字段使用当前 System 字典校验 value，并保存 value、当时 label 和字典类型快照；详情和导出使用快照标签。账号截图等图片/文件字段采用导入后上传，不在 Excel 中携带图片、外部 URL 或 ZIP。台账不读取、不回显、不写入密码内容；`微信密码`列即使存在也会被跳过。

管理端普通附件与分类自定义的“图片/附件”（FILE=6）统一使用带认证及租户上下文的上传流程。上传中禁止保存资产；上传失败保留表单并提示重试，不写入无效地址。单文件字段允许上传首个文件，普通附件支持多个文件。编辑与详情中图片显示缩略图，浏览器支持的图片、PDF、文本及音视频可打开预览，其他格式显示文件名及下载入口；预览失败时仍保留文件名和下载入口。

附件接口仍保存 URL（普通附件为列表，自定义文件字段为单个 URL），不新增数据库字段。当前上传保留原始文件名，重新加载记录后从 URL 路径提取名称；历史 URL 无法还原的原始名称不作推测。存储服务签名地址的有效期与续签机制不属于此次显示修复。

标准列包括：分类编码、资产名称、资产编号、数量、资产状态、购入日期、资产来源、使用人、存放地点、备注。

IT 硬件设备根分类维护选填文本字段 `sn`（序列号），所有子分类通过现有继承机制获得该字段。台账使用 `sn:序列号` 自定义列；非 IT 分类不会自动新增序列号。现有分类自定义的机型、规格等字段不受影响。

品牌型号、规格参数、序列号、条码、原值、净值、保修到期日、预计使用寿命（月）不再是资产固定字段；保存/查询/公开编辑接口与页面已移除这八项。旧 Excel 固定列有值时预检报错，空列忽略；不会静默转成其他字段。导出按分类配置展开自定义列，序列号直接导出文本，字典列使用历史标签快照。

开发基线修正位于 `V006__eam_category_baseline.sql`，前置为 V005，执行顺序保持不变；只给租户 1 的 IT 根分类补 `sn`，并把该树内资产旧 `sn` 非空值补入空的 `ext_fields.sn`。已有自定义序列号不覆盖，其他租户/分类不改，重复执行不重复新增。旧物理列保留但运行代码不再读写；回退代码不自动清除新自定义值。已部署环境需另行审查升级迁移，不重跑开发重置脚本。本地同步只执行该新增片段，不能借此执行 V3 重置。

旧版 54 列、双层表头、迁移残留字段不属于 V3 模板或导入契约。数据库历史列暂不物理删除，但不会出现在分类配置、资产表单、台账模板、预检结果、导入日志或导出页面。

`script/sql/mysql/migrations/eam/reset_eam_v3.sql` 仅用于本地开发人工执行，删除并重建 EAM 自有数据和 V3 分类/字段/编号规则。执行前必须确认数据库名、租户和 EAM 表行数；脚本不删除 System 用户、部门、角色、菜单、权限、字典或其他业务表，也不执行 `DROP DATABASE`、全库 `TRUNCATE`。
