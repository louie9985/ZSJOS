# EAM V3 分类配置与资产台账导入

资产台账只读取工作表 `资产台账`。第 1 行是单层表头，第 2 行开始是资产数据；其他说明工作表不会创建资产。

分类配置模板包含 `分类`、`字段` 两张表。分类按分类编码幂等新增或更新，字段按“所属分类编码 + 字段标识”幂等新增或更新；模板缺失内容不会自动删除数据库记录。

台账主表按表头名称定位，列顺序可以调整；自定义字段表头使用 `字段标识:字段名称`，导入后以字段标识保存。必填业务列为 `分类编码`、`资产名称`。分类编码不存在、分类编码为空、资产名称为空或标准数字/日期格式错误，会进入预检错误并阻止提交。

资产编号为空时由分类编号规则生成；已有资产编号默认跳过，只有显式开启更新才更新。单件分类数量固定为 1；批量分类数量必须为正整数。使用人通过 System 用户 API 匹配，未匹配或重名只产生明确警告并保留姓名快照。

下拉字段使用当前 System 字典校验 value，并保存 value、当时 label 和字典类型快照；详情和导出使用快照标签。账号截图等图片/文件字段采用导入后上传，不在 Excel 中携带图片、外部 URL 或 ZIP。台账不读取、不回显、不写入密码内容；`微信密码`列即使存在也会被跳过。

标准列包括：分类编码、资产名称、资产编号、数量、资产状态、品牌型号、规格参数、序列号、条码、原值、净值、购入日期、资产来源、保修到期日、使用人、存放地点、预计使用年限（月）、备注。

旧版 54 列、双层表头、迁移残留字段不属于 V3 模板或导入契约。数据库历史列暂不物理删除，但不会出现在分类配置、资产表单、台账模板、预检结果、导入日志或导出页面。

`script/sql/mysql/migrations/eam/reset_eam_v3.sql` 仅用于本地开发人工执行，删除并重建 EAM 自有数据和 V3 分类/字段/编号规则。执行前必须确认数据库名、租户和 EAM 表行数；脚本不删除 System 用户、部门、角色、菜单、权限、字典或其他业务表，也不执行 `DROP DATABASE`、全库 `TRUNCATE`。
