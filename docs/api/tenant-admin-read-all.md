## 读取契约

- 个人读取支持可选 `readScope=SELF|ALL|USER`、`targetUserId`，省略保持旧行为。SELF 为个人页面默认；ALL、USER 必须经过 System 全量读取能力检查，USER 的目标须能在当前租户 System 用户 API 解析。未知范围、ALL 携带目标、USER 缺少目标等不能静默回退。
- 当前接入：个人日历、我的学员、业务任务分页和汇总、个人反馈列表、我的工单、个人提现列表、班级个人查询。前端全量／指定人员视图明确只读；反馈不代标记已读，任务不代执行，工单不代接单或验收，提现不代申请或取消。
- `GET /system/user/simple-list?includeDisabled=true` 仅供有能力的管理员读取人员选择，包含停用用户。局部忽略部门数据规则，租户和逻辑删除规则仍生效；默认接口行为不变。
- 状态、日期、关键词、个人分组、我的／收藏、关系类型和业务类型条件仍生效。订单高级筛选不再清空用户选择的状态。
- 非本人业务字段可读不意味着可编辑。账套默认设置、知识库互动与内容编辑、客资分配／转移、审批、支付保持原命令校验。认证秘密不在全量读取范围。
