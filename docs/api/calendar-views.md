# 工作台我的日历与课程日历：日／周／月

两类日历默认月视图，工具栏提供日期跳转、今天、日/周/月和前后周期导航。无年视图、小月历、日历列表或农历。切换视图保留锚点日期；今天按北京时间定位且保留视图；前后分别移动1日、7日或1月。月视图保留原日期格、完整条目与横向滚动，导航统一到顶部。考期及其他日历不变。

## 时间轴
周视图以周一为首日，展示连续7天；日视图仅当天。00:00–24:00完整可滚动，初始定位工作时间附近，当前自然日显示每分钟更新的时间线。全天个人日程固定在顶部；跨午夜定时事件按日期裁切，结束时刻为不含边界，零时长保留1分钟可聚焦事件。事件位置反映实际时长，重叠连通组计算一致列数并排展示。短事件可通过键盘、提示及详情查看全文。

点击30分钟空白格在有新增权限时打开既有表单，预填该时刻和一小时后；无权限时禁用。点击事件打开当天详情并标记所选事件，详情继续使用当前页面的创建人、备注、附件、编辑、删除及通知机制；不新增拖拽改时间、拉伸时长或会议室功能。

手机日视图适配宽度，周视图保持七列最小宽度840px，在时间表内横向滚动，日期栏与内容同步；日期头、全天区和左侧时间刻度固定。深浅主题沿用工作台token，事件使用持久化色值和黑/白对比文字。

## 数据与接口
沿用两类日历现有查询端点，不新增聚合API。日查询当天到次日零点，周查询周一到下周一零点，月查询沿用当前月历可见范围。快速切换继续丢弃旧请求响应。对象可见性、个人只读管理范围及课程管理/通知权限不变。错误、重试、空数据通过现有状态处理，空的时间网格仍可创建。
