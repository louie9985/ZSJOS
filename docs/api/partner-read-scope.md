# 中世健兼职查询范围

2026-10-28 用户确认调整原有部门、独立兼职可见关系叠加契约。

普通 `zsjos:partner:query` 读取本人直接归属兼职，以及 `content_director_operator` 中 source 为本人、status=0 的 target 运营当前名下兼职。关系已由现有人员关系管理维护，不复制或回填到旧兼职可见场景。关系停用或改派影响后续请求；不改变历史归属、业绩和消息快照。停用员工的既有业务归属不因登录状态自动消失；查询者必须启用。

旧 `zsjos:partner:manage` 保持本人只读；与 query 同时授权时取并集。System 的部门/全部数据范围不扩大兼职读取。

新增 `zsjos:partner:query-all` 是范围按钮，须同时拥有既有查询入口权限（query、manage 或 manage-all）。它允许读取租户内全部兼职，包括未分配兼职，不允许修改。现有 manage-all 保持全量查询与账号/归属管理命令。真实角色配置由管理员维护；迁移不写角色菜单关系。

统一范围覆盖 `/zsjos/partner/page`、旧 `/zsjos/subordinate-partners` 查询、兼职客资列表/详情、客资对象读取和批量可见性校验。列表总数与分页使用同一集合；客资其他独立授权来源继续有效。所有查询保留租户及逻辑删除条件。Vue Admin 与 React Workbench 共用后端，说明文字区分本人、本人及关联运营、全量读取和管理；前端不自行计算关系范围。
