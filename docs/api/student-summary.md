## 已确认权限例外

`zsjos:student-summary:query` 允许读取当前租户（当前系统唯一租户为 1）全部未逻辑删除的教务服务及对应汇总字段，不叠加个人负责人/部门范围、原档案 read/sensitive-read 或考试字段可见性。包含服务已暂停、完成、终止、教务关闭的历史记录。授权来源仍为 System 菜单权限，后端独立检查；不按角色名称或账号 ID 判断。

`zsjos:student-summary:export` 累加 query 才能导出。该例外仅用于汇总读接口，不授予原档案详情、材料下载或修改能力，原 Admin/Workbench 学员管理契约不变。接口关闭请求/响应内容日志，数据响应 no-store；浏览器只保存列偏好，不保存学员内容。

## 接口

前缀 `/admin-api/zsjos/student-summary`：

- `GET /columns`：有序字段目录 `{key,label,group}`；报名字段标签优先使用当前已发布配置，保留固定字段全集以便历史资料可读。
- `GET /classes`：当前租户的班级候选，包含在服、结课及待分班等实际班级，展示班主任与考期快照。不要求另行持有班级管理权限。
- `GET /page`：`pageNo`、`pageSize`（1–100）、`classId`、`keyword`（姓名/手机号/学员编号），返回 `PageResult<{serviceRelationId,values}>`。班级条件与学员管理相同，匹配服务当前 `class_id`。按服务更新时间倒序、内部服务 ID 倒序稳定分页。
- `POST /export`：上述筛选条件加有序 `columns` 字段标识，输出 `.xlsx`。忽略分页，导出全部匹配记录；拒绝未知、重复或空列。使用与列表一致的投影，按每批 100 条读取，在一致读事务内完成；单表超过 Excel 上限明确拒绝，要求缩小筛选。

列设置支持显示/隐藏、拖动排序及固定列；导出顺序包含固定列在左右两侧的实际顺序。Excel 标题来自同一后端字段目录，电话/身份证等以文本单元格写入。未显示的列不导出，不包含操作控件。

## 数据口径

按用户纠正，表格与 Excel 只包含学员档案：报名收集资料全部字段、扩展档案全部字段，以及资料提交状态/时间。移除订单、课程、负责人、服务状态、服务起止时间、联系方式主档等非档案列。姓名、手机等档案列展示报名档案自身值，不用服务或 Person 当前值替代。另按本次对比需求增加“学员·姓名”（服务姓名快照）和“学员·手机号”（关联 Person 当前手机号），分别使用 student.name/student.mobile，默认前四列为学员·姓名、学员·手机号、姓名、手机号码。两组独立取值，缺失不互相回填；列表及导出一致。服务关系仅用于行标识和档案归属，班级仅用于筛选。

报名表批量解析沿用 `StudentInfoFormMapper.byCase` 的直接报名关联及订单资料任务关联，取匹配的最新表单并核对 Person 与订单商品。不得改用同一人的其他课程档案。已提交资料优先读最新档案修订；无修订时读原答案。字典和地区显示已保存的历史标签，不查当前字典重写历史含义。默认展示全部服务；最新关联表单已提交标记“已填写”，无表单或草稿标记“未填写”，不读取草稿答案。

扩展资料取最新服务修订；证书邮寄地址没有内部覆盖时沿用该服务报名资料。附件列包含当前修订选中的文件名称（旧材料无原名时沿用系统名称），不包含二进制图片或永久下载 URL。修订、答案、材料按页批量读取，不在浏览器逐个拼接详情。
