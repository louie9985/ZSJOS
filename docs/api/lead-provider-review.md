## 2026-10-11 来源关系语义

共享客资概览及订单客资投影采用“业务来源”“来源人员”；providerIdentityLabel 的新媒体标签为“新媒体提供方”，表达该记录的来源关系，不表示员工当前岗位。字段名、类型、权限和身份遮蔽规则保持不变，旧响应缺少标签时继续显示身份待核实。
