# 审批任务列表状态

`GET /admin-api/bpm/task/todo-page` 的每条任务通过 `status` 返回 BPM 任务本地变量中的真实状态，沿用 `BpmTaskStatusEnum`。状态属于当前任务，不是业务单据或整个流程实例的状态；不得根据列表类型统一填充“审批中”。

Workbench 审批中心和 Vue Admin 共用该接口。状态缺失时保留空值，由消费者明确显示缺失提示，不伪造历史或当前状态。即使流程摘要暂时缺失，任务自身的状态仍返回。分页总数、排序、权限与流程摘要契约保持不变。

回归验证：`BpmTaskConvertTodoStatusTest` 覆盖多任务不同状态、摘要缺失、状态缺失与空分页。该修复不涉及数据修复；运行环境需要更新后端才会生效。
