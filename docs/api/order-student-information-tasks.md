## 业务与权限

- 每个订单商品明细一项任务，不按 quantity 复制同一学员的表。租户/明细唯一约束和订单锁防止重复创建。
- 任务不立即产生公开链接。报名服务在“查看已有档案”弹窗中查看相同 Person 的唯一当前档案，可确认复用或生成新表；当前档案采用最新正式提交表单的最新修订，不再列出多份历史来源。
- 必填字段按稳定 key、类型、字典类型检查，附件核对格式、数量、大小及身份证正反面。缺项禁止直接复用，但允许生成新表带入兼容内容。
- 复用留存本次资料快照、源表、源修订和操作人；不改原答案。附件创建独立加密文件，删除新表材料不影响历史文件。
- 订单终止/被接续时禁止内部生成、复用、确认发送及读取公开链接；已有公开链接仍按原有效期保存和提交，不因订单终止被撤销。
- 履约公共池仅读取同一任务的表单与状态，复用可满足原先的已发送完成条件，但不伪造发送时间。旧生成/发送/取链接 API 提示到统一任务办理；资料读取和导出保留原对象权限。
- 统一列表累加 `zsjos:student-info-task:query` 与既有 `zsjos:registration:query-pool`，沿用报名公共池的租户范围；不按角色名授权。
- 生成、读取链接、确认发送沿用 `zsjos:student-info-form:create/link-read/sent`；直接复用使用 `zsjos:student-info-task:reuse`。生成/复用累加敏感资料权限。迁移只定义菜单，不授予角色权限。

## 接口

ADMIN 基础路径 `/admin-api/zsjos/student-info-task`：GET `/page`（pageNo/pageSize/keyword/personId）、GET `/{id}`、GET `/{id}/link`、POST `/{id}/generate`、POST `/{id}/reuse`、POST `/{id}/sent`、POST `/{id}/regenerate`、GET `/{id}/information?sensitive=false`、GET `/{id}/images/{imageId}`。
命令包含 version、idempotencyKey，可选 sourceFormId/sourceRevision。候选只返回来源项目、修订和缺项，不返回答案明文。响应 no-store，请求/响应日志关闭。公开 H5 保持原 token 协议。

## 资料查看与链接恢复

统一列表支持已提交资料和附件读取；读取最新档案修订、按敏感权限脱敏，附件必须属于当前修订及当前任务的表单。订单终止不阻止历史资料读取，但仍禁止取填写链接。订单页保留按 Person 查询收集任务的导航；收集任务的“查看已有档案”直接弹窗展示，不跳转历史列表。统一列表暂不提供导出，既有履约/学员档案的导出入口继续执行原权限。

过期或未提交表单可用原 regenerate 权限轮换链接，保留字段快照、草稿和附件，清除已发送确认；旧 token 立即不可用，需要重新发送。已提交/已复用表单禁止轮换。

旧任务兼容修正沿用尚未部署的 V359 开发迁移。即使本地已有 V359 台账，重跑仍检查并补齐缺失空任务，保留已有任务及台账校验值。已有任务与订单/客户关联冲突时整段 DML 回滚并报错，不覆盖旧任务。已部署环境不应据此直接重写历史迁移，须另行审查升级路径。

## 唯一当前档案（2026-11-02）

每位客户只有一份当前可查看/复用档案。它由该 Person 最新一次非复用的正式提交表单确定（submittedAt 降序，同时间按内部记录序号确定顺序）；新正式提交会替换当前档案整体内容，不与旧字段拼接。草稿不覆盖当前档案，直接复用产生的订单副本也不会将旧资料重新提升为最新档案。旧订单的答案/材料/来源快照继续作为订单记录保留，不作为可选择的历史档案，不批量删除。

列表 candidates 字段为协议兼容继续保留数组类型，但只能返回零或一个当前档案。查看已有档案先刷新任务当前来源，再按 formId/revision 读取 `/student-info-task/{id}/archive`，材料使用 `/archive/images/{imageId}` 并携带同一来源/修订。资料和材料读取重新核对当前档案、客户与权限；预览失败/尚未完成时不能确认复用。旧来源或修订变化返回版本冲突，应刷新档案；源选择下拉与“历史收集资料”操作已移除。

复用仍完整校验本次要求；缺必填字段或材料则禁止直接复用，可带入已有内容生成新表。已生成但未提交的任务也可在明确确认后复用：保留原字段合同、草稿及附件为订单留痕，撤销原填写链接，将任务绑定到新复用快照。已提交/已复用任务不可覆盖；终止订单不可执行复用。该规则使用既有数据投影，不新增表、不重写旧订单答案，不改变公开提交协议。
