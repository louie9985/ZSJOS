# 中世健认证、导入与业务失败契约

本页记录 2026-10-14 异常日志修复的接口边界。源码及测试结果由交付记录说明；本页不代表目标环境已经部署或验收。

## 刷新令牌

ADMIN 刷新令牌对应账号不存在时返回标准认证失效 `401`。仅撤销该刷新令牌及其派生访问令牌，同时清除相应缓存和以刷新令牌作为访问令牌的兼容缓存。其他设备、客户端和用户的会话不在本次撤销范围内。撤销随认证失效响应提交。

数据库查询失败、Redis 清理失败不转换成“账号不存在”或“登录失效”；保留基础设施异常及事务回滚。MEMBER、PARTNER 继续由其所属业务模块提供资料，不使用 ADMIN 账号是否存在作为失效依据。

## 社交授权与企业微信绑定

| 错误码 | 业务含义 |
| --- | --- |
| `1002018002` | 授权来源为空或当前实现不支持 |
| `1002018003` | 支持的授权来源缺少配置或配置不完整 |
| `1002018004` | 企业微信身份绑定冲突，需要核实已有绑定 |

租户数据库凭证在授权请求对象构造之前应用，即使没有全局占位配置也能使用已配置的租户应用。未配置扩展枚举或扩展配置时不产生空指针；不返回凭据或底层配置内容。

正常企业微信重绑仍在同一事务中迁移已有绑定和用户投影。`system_users.uk_tenant_wecom_user_id` 冲突返回明确业务错误并回滚本次更改。不会猜测或自动清理缺少绑定记录的历史孤立用户投影；其他数据库错误不冒充绑定冲突。

## 用户 Excel 导入

手机号保留原有可选语义；填写时必须是 **11 位 ASCII 数字**，并继续通过已有手机号号段校验。`+86`、`0086`、非数字和长度不符均计入该行失败原因，不去前缀、不截断、不扩大数据库字段。失败行不插入或覆盖账号，后续有效行继续处理。

## 申诉、投诉附件与礼品

历史附件缺少文件 ID，或 Infra 无法解析该 ID 时，保留附件元数据，下载 URL 为空。仅使用 Infra 返回的签名 URL，不回退到无法验证的旧 URL；签名服务错误仍按原错误传播。

礼品重复编码继续拒绝创建或更新，返回业务错误 `1900095000`，不再作为未知系统错误。其他礼品校验及唯一性语义不变。
