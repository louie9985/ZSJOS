# 中实建审批表单附件上传

管理端文件上传组件与表单设计器共用 `frontend/admin/src/components/UploadFile/src/fileTypes.ts` 的默认格式：doc、docx、xls、xlsx、ppt、pptx、txt、pdf、zip、rar、7z、jpg、jpeg、png、gif、webp。同一附件字段可混合选择这些文件；提示和上传前扩展名校验均使用实际的 `fileType`。

新建文件上传字段在规则的 `props.fileType` 中保存默认列表。没有配置 `fileType` 的旧字段使用组件默认值。已有显式配置不会被自动追加或覆盖，空数组保留现有“不限制扩展名”的语义。

已有字段若明确限制为办公文档，请在设计器选中原字段，在“文件类型”中加入需要的图片、压缩包格式后保存，不要删除重建字段。流程定义或已启动实例若使用表单快照，需要分别核对其实际配置；修改设计器不等于改写已发布定义或历史实例。本次不迁移数据库、表单规则或流程快照。

前端代码更新后需确保页面加载最新资源。默认值也影响未显式传入 `fileType` 的其他管理端通用附件入口；显式限制不变。通用附件默认单文件上限 100 MB，新建字段持久化 `props.fileSize: 100`；已有显式 `fileSize` 保留，需在设计器修改并按流程重新发布。审批操作附件上限同步为 100 MB。存储、权限与服务端检查仍以现有上传接口为准。
