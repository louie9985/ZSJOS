# 中世健审批中心同页审批

审批中心保留待办／已办切换，详情内部不再使用页签。业务字段、理由、附件位于左侧；右侧按服务端节点顺序连续展示处理人、时间、结果、意见、签名、附件和流程评论。任务 ID 用于归并，名称不用于去重；加签子任务按父任务归属，未覆盖任务保留在补充流转记录中。需求审批使用任务所属轮次业务快照。

待办／已办收件箱主标题与表格「任务」列统一优先显示服务端流程实例名称，缺失时使用任务节点名称，均缺失时显示「审批任务」。业务摘要的 `title` 可能只有批次号或单号，因此只用于次要摘要，不覆盖主标题；不在前端维护流程名称映射，也不改写历史流程名称。

内容审核（`zsjos_production_content_review`）、爆款内容拆解和爆款账号拆解（`zsjos_viral_content_review`、`zsjos_viral_account_review`）在工作流程待办中直接处理。两类爆款拆解不再从待办、已办及其计数中排除；订单与客资申诉维持原入口规则。

这三类任务的详情复用业务页组件，隐藏业务页自身的列表和管理入口。内容审核通过经授权的业务内容卡 `query.batchId` 定位批次，保留账号快照、正文、附件、逐条结论、终审收录选择及整批通过／退回；爆款拆解通过现有任务定位接口加载原素材快照及通过／驳回表单。全部操作仍调用原业务接口，不使用通用 BPM 通过／拒绝绕过业务校验。任务定位或业务读取失败显示错误和重试，任务已流转则只读；已办不显示决策操作。

任务切换、关闭详情与刷新遵守未保存意见和提交中保护。成功处理后刷新任务列表及数量，保留结果并可进入下一条待办。桌面、表格抽屉和移动抽屉共用一个业务详情实例。嵌入界面的未保存状态交给待办页面管理，不覆盖独立内容审核页的关闭守卫。没有新增授权或业务流程定义；新增的内容卡查询参数为兼容性元数据，Admin 原有流程表单不变。

## 布局

桌面详情为 9:3 分栏，正文和右侧历史独立滚动，操作区在右栏底部。以详情容器 1100px 为切换边界；窄容器按业务、流程、评论依次展示，通过“处理审批”展开操作区。同一任务只有一个详情实例，表格和移动场景使用现有详情抽屉。样式仅作用于审批中心，内容审核等其他 BPM 消费者保持原布局。

## 操作与草稿

任务分页响应携带真实 `processDefinitionKey`，业务分流使用该字段，不从流程定义 ID 或名称推导。
素材通过／驳回的独立权限在后端决策边界校验，通用 BPM 入口也不能越过该约束。
内容草稿每次打开重新取得人选上下文并恢复就绪状态；取消后再次打开同一草稿仍可提交，关闭中的表单不继续初始化人选。

通过／拒绝直接填写意见，沿用节点 reasonRequire、signEnable 及 500 字限制，校验后确认提交。转办、委派、加签、减签、退回、抄送保留原弹窗和接口。节点配置、任务匹配、任务状态及 bpm:task:update 权限共同决定可处理性；已办只读。评论输入保留在流程评论区域，独立于审批意见。

草稿仅存在于当前任务的页面内存。任务切换、搜索、关闭抽屉、工作台关闭守卫、浏览器返回和同源链接离开均检查未提交输入；提交中阻止离开。刷新保留草稿，失败保留输入及明确错误。终结或移交任务的动作成功后保留当前结果，提供下一条待办；抄送、加减签等非终结操作仅刷新，不自动切换下一条。

## 数据与验证

详情、业务卡、流转记录和评论独立加载、重试，请求序号防止旧响应覆盖最新数据；失败不展示为正常空列表。业务卡不支持时仍保留既有表单兜底，业务读取失败明确提示。无新增接口、依赖、SQL、角色授权或 Admin 修改。

验证入口：npm run typecheck；定向 Vitest approvalHistoryModel、bpm-approval-labels.guard 和 bpm-approval-actions.guard；python test/approval-center-layout-browser.py（使用既有本地 Vite 5174，全部请求在 fixture adapter 内终止）。浏览器覆盖 1920/1440/1024/768/390、表格抽屉、需求审批、签名必需、草稿保护、失败重试、评论、已办和深色主题。fixture 是隔离组件证据，不代表已登录运行环境或生产审批验收。

三类业务任务验证：独立 Vite 5198 下执行 `python -B test/unified-business-approval-browser.py`。所有 HTTP 请求均由测试 adapter 截止，覆盖原业务命令、编导与终审、批次退回、爆款通过／驳回、未保存提醒、失败重试、已办只读、权限及任务变化、表格抽屉和桌面／移动显示。后端需同步部署内容卡批次定位元数据；未同步时界面明确提示并阻止通用审批兜底。


业务审批页卸载会释放其宿主的未保存/提交中状态；提交成功后即使已办详情加载失败，也可关闭或进入下一条待办。
