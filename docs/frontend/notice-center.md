# 员工公告阅读页

`/messages/notice?announcementId=...` 的列表查询与详情选择独立。点击公告只请求所选正文、更新地址和已读状态，不重置列表、游标或列表滚动位置；地址中的公告编号变化同样只加载详情。详情加载失败在详情区域重试，不触发列表刷新；快速切换以最后一次选择为准。

我的公告页占用工作台内容区剩余高度，页签与搜索栏固定，桌面列表和正文分别内部滚动。移动端保留内部滚动列表，点击后通过底部抽屉阅读正文。沿用全局主题圆角和间距。列表使用现有游标接口每次追加 20 条；触底加载，追加失败停止自动重试并允许手动重试同一游标。刷新或搜索废弃旧请求，防止过期结果混入；正文按选择加载，图片沿用懒加载。

来源部门与发布人展示服务端快照；历史空值仍显示“未记录”，不按当前组织或创建者推断，详见[公告来源契约](../api/notice-origin.md)。没有在此页面补填历史业务数据。

公告正文图片支持点击或键盘 Enter/空格打开大图。工作台与管理端复用各自已有图片预览组件，支持缩放、切换同一篇正文内的图片及关闭；切换正文会清除旧预览。图片本身带链接时优先预览，链接中的普通文字保留原跳转。此行为仅用于公告正文，不改变保存内容、其他业务富文本或附件授权。

列表当前选中的公告使用主题主色浅底、左侧主色标记与主色加粗标题；鼠标移开或公告标为已读后仍保留选中标识，切换公告时跟随当前选择。普通悬停使用中性底色，键盘焦点显示主色轮廓。颜色沿用主题变量，移动端关闭阅读抽屉后仍可辨认当前选择。

隔离验收：`test/notice-center-scroll.html` 与 `test/notice-center-scroll-browser.py` 使用正式组件及合成响应验证浏览器行为，不代表共享测试环境已部署或真实账号验收。

公告 PDF 附件通过工作台共用附件组件预览：沿用业务接口重新获取的临时地址，读取并校验响应类型与 PDF 文件头后，创建 `application/pdf` Blob 交给浏览器内置查看器。PDF iframe 不设置会阻止 Edge/Chromium 内置查看器的 sandbox，但只接收校验后的 Blob，不直接加载远程页面。关闭、切换和卸载时取消请求并释放预览地址；图片、音视频及原文件下载保持原有流程。跨域文件服务需允许工作台读取响应（CORS），不附加登录凭证；网络、访问失效、文件移除、类型错误分别提示，支持重试及下载原文件。此变更同样覆盖工作台其他复用 AttachmentCard 的 PDF 预览，不改变业务授权或管理端/H5。

PDF 隔离验收：`test/notice-pdf-preview.html` 与 `test/notice-pdf-preview-browser.py` 使用正式公告附件组件及合成 PDF，在 Edge 检查内置预览、失败重试、非 PDF 拒绝、下载和资源释放。
