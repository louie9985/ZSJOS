# 公告正文表格

员工工作台公告继续使用现有富文本编辑器。工具栏可新建表格，选中单元格后可使用表格菜单调整行列、合并单元格及单元格属性；鼠标移到列或行边界，出现调整光标后拖动，可调整列宽或行高。复制富文本表格后应先检查预览，再保存草稿。

公告预览、管理详情、阅读详情及工作台对外分享预览，通过 `SafeRichText` 的 `announcementTables` 开关开启表格适配。开关默认关闭，素材库等其他调用方保持原有展示。外部公开阅读使用下述独立的服务端安全投影。

每张表格有独立的横向滚动区域，可用触控、鼠标或聚焦后左右方向键查看其他列。保留正文中的固定布局、像素列宽、行高、颜色、对齐及 `colspan` / `rowspan`。像素表格、colgroup 和单元格宽度作为显示时的尺寸下限，未指定宽度的列以 80px 估算表格最低总宽度；明确的列宽优先。百分比宽度仍按容器计算。基础边框和内边距采用工作台主题，显式内联样式优先。滚动包装和显示下限仅用于阅读投影，不写回正文，不修改历史记录。

公开分享的服务端 HTML 页与旧 H5 页使用 `NoticeShareContent` 的同一份正文投影：保留表格及单元格内安全的尺寸、行高、固定布局、边框、颜色、对齐、内边距及基础字体样式。只放行有限属性和值，不开放任意 CSS；URL、表达式、转义、变量、定位和覆盖页面的样式仍会被删除。服务端生成独立可聚焦滚动容器和像素宽度下限，客户端提供匹配的表格边框及间距，百分比宽度随正文区域变化。重复清理不会叠加包装。此修复不修改历史正文；原正文已经丢失的格式无法凭空恢复。

公开表格回归入口：System `NoticeShareContentTest` 导出真实清理后的样例；`frontend/h5/tests/notice-share-tables-browser.py --fixtures <System模块>/target/notice-share-tables --dist <H5构建目录>` 同时验证服务端无 JavaScript 阅读页及 H5 页。覆盖像素/百分比/单元格宽度、合并单元格、中文长文本、颜色与边框覆盖、横向滚动和无表格正文。

载入的表格可能尚无编辑器内部高度元数据，导致列宽拖动区域为零高。公告专用容器将该区域锚定到实际表格高度，并仅允许边界接收鼠标事件，保留单元格正常选中、输入和菜单操作。

工作台公告通过共享编辑器的可选 `tableAdapter` 启用尺寸适配，日历说明与 Vue 管理端不启用。载入、外部重置及 HTML 粘贴时，将 `pt` 等物理尺寸按浏览器 CSS 像素转换；有 colgroup 时保留明确列宽，否则结合全部行的 colspan/rowspan 网格，优先采用独立单元格宽度，再分配合并单元格及表格的剩余宽度。没有尺寸依据的列沿用编辑器的 90px 默认值；相对/绝对混合且无法确定基准的布局保留原生解析，不臆造容器尺寸。正文文字与合并关系保持不变，未打开并保存的历史记录不改写，已经丢失的原始尺寸不能自动恢复。

行高拖动按实际显示的行边界定位，长中文自动换行后仍可拖动；引导线限制在当前表格可视区域。拖动预览不落入正文，松开后才形成一次修改，Escape 或窗口失焦取消。行高受内容的自然最低高度限制。编辑器 5.7 的表格测量/悬停元数据通过实例级适配隔离于撤销历史，行高、列宽和正文仍走原生 Slate 修改流程；升级编辑器时须重验该历史边界。窄屏表格浮动菜单可换行，隐藏的提示框不再撑宽页面。

回归入口：`frontend/workbench/test/notice-tables.html` 用于新建表格、中文输入、加载样例和重开；`frontend/workbench/test/notice-table-overflow.html` 使用真实公告表单、管理详情、阅读详情、分享预览及内存传输，覆盖固定/百分比宽度、合并单元格、长文本、无表格正文和默认关闭行为。夹具拒绝实际 HTTP 和发布请求。

2026-10-08 验证：1440px 桌面与 390px 手机下，宽表格留在正文区域，能滚动至最后一列。真实鼠标拖动使首列从 200px 改为约 235px、首行从 56px 改为 68px；右对齐支持撤销/重做，经公告表单保存至内存后重开及预览保持一致。新建四列两行表格、中文输入和重开通过。未进行已登录真实后端保存验证；不同 Word / Excel 版本的专有剪贴板格式也未逐一验证，加载样例不代表专有剪贴板验收。
