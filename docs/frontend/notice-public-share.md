# 公告分享使用说明

中世健 Admin 和员工工作台在公告管理列表每条已发布公告的「操作」列提供「对外分享」，与「查看」并列，无需先进入详情。入口要求服务端同时返回公告查询、公告对外分享权限；草稿、已下线公告和员工「我的公告」不提供外发入口。

1. 在公告管理列表找到已发布公告，直接点击操作列的「对外分享」。系统先加载最新公告及附件，再打开分享设置；加载失败时可再次点击重试，状态已变化时会刷新列表。
2. 展开正文预览，确认标题、正文及其中图片、视频适合公开。
3. 按需勾选公开附件，默认不选择。指定部门/人员公告会显示原配置的部门数、指定人员数和已有的发布时接收人数，并提示外部访问不受原接收范围限制；不将当前组织资料冒充历史接收名单。
4. 开启后复制链接或下载二维码，发送给学员、合作伙伴、意向客户。访客无需登录员工或合作方账号。
5. 「关闭分享」使后续打开旧链接失败；修改附件范围需关闭后重新开启，并重新发送新的链接/二维码。

分享页面失效时联系分享人；网络或服务异常可重试；附件失败不影响正文，可重试获取地址。图片、PDF 由浏览器查看，Office、ZIP 下载后打开，不承诺所有手机浏览器具有相同预览行为。

正文图片可直接点击查看大图：H5 使用现有 Vant 预览组件，支持触屏缩放、左右滑动切换和关闭；服务端直出分享页通过页面内链接与 CSS 实现大图、上一张/下一张、关闭及“查看原图”，继续保持 `script-src 'none'`。服务端页的“查看原图”由浏览器提供缩放；图片若带原链接，点击图片优先预览，原链接中的普通文字仍可跳转。正文展示投影不回写公告内容，图片附件仍走原有授权流程。部署对应前端和后端后生效。

新旧分享阅读页均保留公告表格的安全列宽、行高、合并单元格、颜色和对齐，补齐默认边框与间距。手机上宽表格可在各自区域横向滑动，不挤压成窄列或撑宽整页。显示适配不写回原公告，详见[公告正文表格](notice-tables.md)。

新旧分享页均按屏幕宽度自适应：手机使用全宽阅读区，平板随视口展开，电脑居中显示且最大宽度为 1120px；左右留白在 16–48px 之间变化，正文基础字号保持 16px。宽表格在空间充足时完整展示，超出阅读区时仅表格横向滚动，图片和视频随阅读区缩放。旧 H5 分享页单独解除应用的 10rem 宽度限制，并通过带 `.norem` 的 CSS 选择器避免字号和间距被 px-to-rem 再次缩放；其他合作方页面保持原有移动端布局。服务端阅读页采用相同尺寸规则。此调整需部署后端与 H5 后生效。

公开意味着收到链接的人可继续转发。关闭分享不能收回截图、下载文件或已打开内容；已经签发的文件地址可能暂时有效。匿名浏览不计入内部应读、已读、未读。

不自动发布朋友圈，也不接入企业微信主动发送卡片/网页分享 SDK、提取码或有效期。可将二维码保存后由用户自行发布。

H5 默认网页标题及登录页品牌名称为「中世健教育」。新复制的分享链接直接打开服务端阅读页，首次 HTML 响应的网页标题和分享元信息就是具体公告标题，摘要取自公开正文，企业微信无需执行网页脚本即可读取。页面品牌为「中世健教育」，正文及选中的附件可直接阅读。

已开启的分享无需关闭重开：部署后回到管理列表的「对外分享」重新复制链接或下载二维码即可取得新地址。历史 `#token` 链接继续有效，其 H5 页面仍在加载成功后更新标题为「公告标题 · 中世健」，但不具备首次 HTML 的动态标题。新地址能提供正确元信息；企业微信是否展示预览及缓存多久由客户端决定，旧消息卡片不会自动保证更新，应重新发送新地址并实机验收。

实现边界及错误码见 [公告对外分享 API](../api/notice-public-share.md)，外网配置见 [部署说明](../operations/notice-public-share-deployment.md)。
