# 考期日历富文本说明栏

员工工作台 `/calendar/exam-calendar` 在日历右侧展示“日历说明”。同一租户统一维护一份，与月份和发布状态筛选无关。初始为空，不填充业务项目。

## 展示和编辑

- 桌面为12列 Grid：含侧边导航的日历占9列，说明占3列；说明随页面滚动。≤768px 时说明置于日历上方，保留现有日历手机导航和横向阅读方式。
- “放大查看”打开1000px宽只读 Modal，“编辑”打开同宽编辑 Modal；均受视口宽度限制，正文独立滚动。查看者无编辑入口。
- 说明标题右侧使用轻量操作区：放大为带文字提示和无障碍名称的图标按钮，编辑为主题浅色按钮。手机端点击区至少44px高，标题和操作空间不足时自动换行；弹窗靠近屏幕上方，正文高度随动态视口收缩，保留标题和底部操作空间。
- 复用 wangEditor，支持标题、加粗、斜体、下划线、文字颜色、背景色、列表、链接、表格、图片、撤销和重做。图片可上传或粘贴，表格遵循编辑器原生操作。图片插入到正文段落中。
- 支持预览、保存和取消；未保存关闭时提示。保存失败保留输入，上传失败可重试或移除，上传中和仍有失败项时禁止保存。
- 版本冲突后保留输入，点击“加载最新内容对照”打开最新只读内容，同时合并最新图片映射并保留草稿使用的旧URL映射（同一图片的新旧签名URL均可识别），用户合并后再保存；再次发生并发修改仍由后端拒绝。
- 说明独立加载并可失败重试，不阻塞月份切换、日期详情和多日考期。

## 内容及图片协议

正文最多5000字、HTML最多200KB、最多20个图片节点。仅支持10MB以内的PNG/JPEG/GIF/WebP；前端校验类型和大小，服务端另校验实际文件头。上传文件由Infra存储，说明域保存租户、上传者及绑定信息，不复用公告权限或业务目录。

持久化HTML的图片src为`exam-note-image:<fileId>`。读取时附带图片编号及临时展示URL，前端映射后交给编辑器/展示组件；提交前还原稳定引用。外链图片、Base64图片及未识别图片引用不能保存。URL不作为归属证明，后端只允许当前说明已绑定的图片或当前用户在本租户上传的未绑定图片。

侧栏、只读弹窗和编辑预览共用白名单渲染；图片适应容器，表格局部横向滚动。取消编辑、移除图片不会物理删除文件；未绑定资源保留，不自动清理其他数据。读取签名默认有效一小时，刷新页面可重新取得地址。

## 复用边界与验证

`ConfigurableRichTextEditor`提供编辑器生命周期和可注入上传；公告保留原工具栏和图片/视频上传适配器。说明每次打开编辑器使用新实例，避免输入时HTML回写替换Slate节点；公告保留外部内容更新能力。

隔离浏览器入口：`frontend/workbench/test/exam-calendar-note.html`，仅供验收；API传输为模拟数据并明确拒绝真实业务请求，不挂入生产菜单。
