# 中世健产品规格展示清单

## 边界

只有考期安排接受可选规格条件。其他业务选择器、价格、校验、命令及既有未明确选项不变。
展示组件不包含选择或匹配逻辑。各端保留既有 React/AntD、Vue/Element Plus、Vue/Vant 体系，未新增依赖或共享组件包。
新业务选择保存字段和值的标签快照；历史缺失只显示原始字段和值并标记缺失。未改变选择的资料修改保留原快照。

未改变选择保留的是展示快照；价格继续采用原业务更新流程的新校验结果，不以整行旧快照覆盖价格。
学员接口 `attributeValues` 保持旧的原始值、空值过滤和去重约定；新页面读取 `specs`，不同字段的相同值不合并。
