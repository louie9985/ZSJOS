# 公共池报名履约详情

员工工作台报名履约公共池在现有任务列表右侧展示流程引导详情。仅调整 Workbench 公共池；学生交付、履约配置和 Vue 管理端不受此布局影响。

## 展示与操作

- 顶部固定学员、产品、规格、订单与任务状态；详情内左侧 45% 展示订单/学员、当前交付、折叠的首次分班记录及终态结果，右侧 55% 展示办理流程。字段使用平面标签和值。
- 桌面两列独立滚动，右侧操作条留在内容滚动区域之外。详情容器小于 760px 改为信息在前、流程在后的单列，底部操作条吸底。手机通过任务卡片打开详情，通过“返回列表”回到列表。
- 步骤为确认分班、核对履约事项、完成履约；不新增强制逐步解锁。分班保存建立交付，完成报名仍受财务及服务端完成条件约束。已建立交付后禁止覆盖分班并提示在班级管理转班。
- 班级和历史负责人选项、任务清单及权限使用原服务端来源。人工确认和必传附件分别计数；选传附件不计入必传进度。学习规划师说明和历史分配保留。
- 清单勾选等待服务端保存成功再更新；错误展示在对应项附近。附件保留文件上传、剪贴板上传、预览与删除，格式和每项最多 9 个文件规则不变。
- 保存、上传、删除、完成和关闭期间锁定相关写入控件与完成按钮。完成资格使用服务端 completable；本地未保存和请求中状态只能进一步禁止完成，不推断可完成。
- 分班未保存时，切换任务、分组、关键词、筛选、分页、刷新和手机返回提示继续编辑或放弃修改；不会自动保存。浏览器关闭/刷新使用原生离开提示。应用外部路由导航不新增全局拦截。
- 详情和修改响应通过任务身份及请求代次隔离，防止切换后的旧请求更新当前详情。加载失败可重试；终态只读，保留时间和原因。结束本产品仍沿用原权限、原因弹窗、版本及幂等契约。
