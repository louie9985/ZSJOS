# 考期备注附件

工作台“考期日历”的单条考期备注支持图片和文档附件。此能力属于考期记录，与页面右侧租户共享的“日历说明”独立。

## 编辑与查看

- 原备注保留1000字文本和网页链接；附件单独保存，不占文字额度。
- 新增、编辑和撤销后重新编辑共用附件选择器，支持多选文件和粘贴截图。支持 PNG、JPEG、GIF、WebP、PDF、DOC/DOCX、XLS/XLSX、PPT/PPTX，单文件最多100MB，每条考期最多10个。
- 点击保存草稿或保存并发布时上传。失败项保留，并显示原因；再次保存仅重试失败项，已上传成功项不重复上传。任意上传失败时不保存考期、不发布。保存或发布失败保留输入及已上传文件。
- 当天单日/多日安排及多日抽屉显示附件名称和预览/下载入口。图片、PDF使用现有附件预览，Office文件下载后打开。读取、预览、下载均重新取得签名地址，失败可重试。
- 未提交时移除或取消只放弃引用，不物理删除存储对象。服务器保存的草稿附件可随编辑移除；已发布记录继续遵循原撤销再编辑规则。

## 存储与授权

新增 `attachmentIds` 请求字段，后端在 `zsjos_exam_schedule.attachment_ids_json` 保存稳定文件编号；响应 `attachments` 提供文件名称、类型、大小及临时访问地址。旧客户端省略字段会保留已有附件，显式空数组会清空；旧记录没有附件。

上传要求管理考期权限，服务端验证实际文件类型、大小，并按当前租户和上传人生成专用目录。保存只接受本人的上传、当前考期已绑定附件，或本用户成功领取重新编辑的原考期附件；其他租户、其他业务和其他人的未绑定上传均不能引用。普通查看者只能读取已发布考期附件；管理者的附件读取范围与日历记录可见性一致。隐藏入口不替代后端鉴权。

文件由 Infra 保存；附件读取接口校验考期对象及文件绑定后再签名。新增、更新和附件编号随考期事务保存。附件变更递增内容版本并进入通知版本快照的 `detailsJson`；原通知正文依然是文字备注，不自动向外部渠道投递文件。历史无附件快照的指纹保持兼容。

## 部署和验证

先执行 `script/sql/mysql/migrations/V293__exam_schedule_attachments.sql`，再发布后端及 Workbench。前置为两份账本中的 Core V287；V288–V292 为独立功能。该迁移仅增加可空 JSON 列和版本登记，不回填业务数据或分配权限。重复运行及部分失败恢复均检查实际结构；DDL不可依赖事务回滚，应用回退时保留新增列和文件。

验证脚本：`python -X utf8 -B script/sql/mysql/tools/test_exam_schedule_attachments.py`。`--apply-dev` 仅用于已经授权的本地开发库，先备份目标表和账本再增加列；`--fresh` 创建并保留独立数据库运行完整迁移链。隔离前端验收使用 `frontend/workbench/test/exam-attachments.html` 和配套浏览器脚本。模拟传输不代表真实 ADMIN 登录及 Infra 存储投递验收。
