## 🐛 常见问题排查

### 问题 1：前端菜单不显示
**排查步骤**：
1. 清除浏览器缓存（Ctrl + Shift + Delete）
2. 退出登录，重新登录
3. F12 打开开发者工具，检查 Console 是否有报错
4. 检查用户是否真的有财务主管角色

### 问题 2：API 返回 404
**排查步骤**：
1. 确认后端服务已重启
2. 检查后端日志，搜索 `PaymentSubjectController`
3. 访问 Swagger 文档：`http://localhost:48080/admin-api/swagger-ui.html`
4. 查看是否有 `zsjos/payment-subject` 相关接口

### 问题 3：权限验证失败（403）
**排查步骤**：
1. 在数据库执行我生成的 `final_check.sql`
2. 确认财务主管有 6 个权限
3. 确认当前登录用户确实拥有财务主管角色
