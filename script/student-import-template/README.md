# 中世健学员导入模板生成器

## 在Excel中直接配置下拉

新增 --editable-config 模式，生成可直接维护的五张配置页：配置_课程、配置_规格、配置_人员、配置_班级字典、配置_地区。将 generate.py 和 editable_config.py 放在同一目录。下拉使用普通单元格区域、INDEX/MATCH及逐行计数，不依赖FILTER、UNIQUE或动态数组溢出引用；计算模式应为自动。各版本Excel/WPS桌面交互尚需实际验证。

```bash
python3 generate.py --host '生产数据库地址' --user '已有只读账号' --ask-password --database '实际生产库名' --rows 200 --extra-class-name '往期已拿证' --editable-config --output './学员导入模板_可配置版.xlsx'
```

在配置页预留空白行直接输入选项，将启用设为“是”；停用改为“否”。规格填写所属课程，编导/生涯规划师填写上级学习规划师，运营填写上级编导。班级及资料字典按“字段类型”区分。配置范围写在工作簿“使用与配置说明”，默认每类至少300行、地区在现有数据后额外预留100行；空行不影响，范围外不自动收录。

下拉直接从配置页动态计算，修改后无需重跑脚本。原始系统映射不随手动改名而重写；配置页最后一列比较生成时的原始快照，新项或修改项标“待系统确认”。此功能是离线拟定配置，不会创建系统班级、修改系统字典或授予权限。往期已拿证作为待映射项保留。重复启用配置、失效的旧选择会标红；不要覆盖浅蓝公式列或删除隐藏计算页。

规格及协作者联动采用INDIRECT读取明确的共用列表区域地址；不使用IFERROR包裹INDEX范围，避免某些表格软件将下拉来源转换成单值0。未选上级或找不到关联时引用空列表，保留现有填写内容，不自动覆盖选择。

原动态数组版曾出现下拉仅首项问题，现使用普通单元格区域与INDEX/MATCH，不使用动态溢出引用。规格和人员选项按上级分组共用，所有学员行引用同一份配置级列表，不再每行复制筛选矩阵；通用列表保留生成时缓存。小样例已验证新增/停用课程及规格属性带出，辅助区域大小不随学员行数增长。完整文件约0.8MB；尚未完成桌面Excel全量交互验证。

只需将 generate.py 复制到生产服务器。使用 Python 3.9+ 标准库，无需安装第三方 Python 包、Excel、Node 或 Codex；不读取本地 Excel/JSON 快照。

## 必填列

| 姓名 * | 手机号码 † | 微信号 † | 课程名称 * | 课程规格名称 † | 班级名称 * | 学习规划师姓名 * |
| --- | --- | --- | --- | --- | --- | --- |

前七列固定如上。姓名、课程、班级、学习规划师必填；手机号和微信至少填写一项。课程规格为条件必填：多个有效规格时必须选择；只有一个时可以留空，属性自动按唯一规格带出，后续导入器须解析为该规格。没有有效规格时无法确定交付内容，须核实配置，不能任意生成规格或从班级名称推断。其余输入全部选填，包括收集资料和材料。红字为必填/条件必填，黑字选填；保留全边框并冻结首行和前七列。一行代表一位学员的一项课程。

多规格未选、无有效规格或旧规格与课程不匹配时，规格格会标红。Excel删除/粘贴可能绕过验证，标红是填写提示，正式导入必须服务端阻止未确定规格的记录。单规格留空不会把规格文字写回输入格，唯一规格在“规格判定”表中明确，自动属性和未来导入解析均使用该唯一项。

## 直接连接 MySQL

服务器需要 Python 3.9+、MySQL 8 客户端和已有可读取相关配置表的账号。优先使用已有只读账号，不需要改变生产账号或权限。

```bash
python3 generate.py --host '生产数据库地址' --port 3306 --user '已有只读账号' --ask-password --database '实际生产库名' --rows 500 --output './学员导入模板.xlsx'
```

密码交互输入。也可使用 --password-file 指向已有受保护密码文件，或已有 MYSQL_PWD 环境变量，不把密码放在命令行参数中。

使用已有 MySQL 客户端配置文件（可包含 TLS 参数）：

```bash
python3 generate.py --defaults-file '/实际路径/mysql-readonly.cnf' --database '实际生产库名' --rows 500 --output './学员导入模板.xlsx'
```

--defaults-file 对应 MySQL 的 --defaults-extra-file。数据库名必须显式提供，不推断环境、主机或数据库；文件使用既有 [client] 配置。

## 数据库在 Docker 中

宿主机需要 Python 3.9+ 和 Docker CLI；容器内需有 mysql 客户端。使用真实容器名、现有账号及该账号对应的现有密码环境变量：

```bash
python3 generate.py --docker-container '实际MySQL容器名' --container-user '实际数据库账号' --container-password-env '账号对应的密码环境变量名' --database '实际生产库名' --rows 500 --output './学员导入模板.xlsx'
```

密码只在容器内读取，不输出、不进入参数。宿主机不需要 MySQL 客户端。Docker secret 文件认证请改用直连/客户端配置文件方式。

## 数据和选择规则

用户明确要求的临时历史归类名称可通过 --extra-class-name '往期已拿证' 加入模板。它不创建数据库班级，不生成虚假ID，也不改变服务状态；如当前库已有同名可用班级则复用并去重，否则在班级参考和映射表标明“待映射”。导入前必须明确真实班级或实现经确认的历史归类处理，不能直接将此选项当成已存在的班级。默认不传此参数时，班级仍全部来自当前数据库。

- 固定租户1；System字典和地区为共享系统配置，按有效状态读取。
- 资料配置只读取大写 PUBLISHED；民族、复训、学历、报名层次按该配置的 dictType 解析。字典类型和条目都必须启用且未删除。性别沿用源码固定 system_user_sex 绑定。不会用草稿或本地选项补齐。
- 课程启用且叶分类及其祖先链有效；SKU属于该课程并启用，属性和值须有效。分类、规格说明和属性说明自动带出。
- 班级读取 SERVING 的未删除班级。Excel只验证班级选项存在，课程/班级/负责人兼容性仍需导入器校验。
- 学习规划师来自有效报名关系；编导、生涯规划师跟随规划师，运营跟随编导的配置关系。
- 可加 --source-user-id 实际用户ID，限定某位导入人的规划师关系。不传则使用有效关系并集。这只是运行参数，不要求学员填写ID，也不代表认证或权限授权。
- 重名人员的显示项附账号，重名班级附现有业务班级号，重名课程附分类，重名规格附属性；全由程序生成，用户只选择，不手填编号。仍无法唯一识别则停止生成。
- 地区选择当前系统有效完整路径。必要的显示值与标识映射保存在工作簿隐藏表中。

## 安全执行与重跑

只执行 SET、只读事务、SELECT、COMMIT。所有读取使用同一连接、utf8mb4、REPEATABLE READ一致性快照。没有 DDL、DML、迁移、学员导入、权限修改或服务启动操作。

读取表：zsjos_product、zsjos_product_category、zsjos_product_sku、zsjos_product_attr、zsjos_product_attr_value、zsjos_user_relation、zsjos_delivery_class、zsjos_student_info_form_config、system_users、system_area、system_dict_type、system_dict_data。只读取所需字段，不输出账号密码、学员数据或完整人员资料。

缺表、缺列、查询失败会停止，不跳过、不用旧数据。多个PUBLISHED配置、歧义标签、失效SKU属性会停止。必填课程/班级/规划师无选项时停止；可选字典/协作者缺配置时保留灰色只能留空的字段，并在命令输出和填写说明中提示。

默认拒绝覆盖已有文件。需要覆盖空模板时明确加 --overwrite；文件被Excel占用时换新文件名。--rows 为1到10000，默认200；按实际填写规模生成，避免自行追加没有校验的行。

## 验证及交付边界

运行测试：

```bash
python3 -m unittest discover -s script/student-import-template -p 'test_*.py'
```

此脚本只生成模板，一键导入器尚未实现。导入仍须验证身份匹配、权限、幂等、当前配置、课程班级、人员候选及生命周期约束；无订单历史服务的资料接入不得伪造报名任务。

Excel打开后自动重算；改变上级不自动清空旧下级，不匹配会标红。粘贴可能绕过验证或覆盖公式，服务端仍须强校验。生成文件含必要业务配置和人员姓名，应按业务文件管理。

已在本地MySQL8只读验证，不代表生产执行。生产首次生成后检查填写说明中的时间、PUBLISHED版本、配置提示和首七列，并试选生产课程、规格及人员。
