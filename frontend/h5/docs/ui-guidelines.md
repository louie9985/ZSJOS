# 兼职端 H5 视觉规范

## 主页面顶部间距

- 提交客资、客资列表、收益、我的页面首个内容块距顶部固定为 20px，与首页一致；局部 CSS 使用 `20PX` 保留像素值，避免被 PostCSS 转为随屏宽缩放的 rem。其他内容间距和底部导航避让保持原样。

## 必填标记

- 现有必填标记统一使用红色星号，锚定标签文字右上角，不放在字段左侧或固定宽度标签栏的最右侧。
- Vant 字段保留 `required` 配置，由全局样式定位；自定义标签使用 `h5-required-label`，动态字段仅在接口返回 `required` 为真时应用该样式。
- 申诉输入框使用“申诉理由”标签承载标记；标记位置调整不新增必填项，也不改变现有校验规则。

## 主题材质

- 页面底层统一使用 `--h5-app-background`。珊瑚粉、天空蓝和薰衣草紫使用各自的浅彩色渐变画布。
- 普通内容面板使用 `--h5-content-surface`、`--h5-content-border` 和 `--h5-content-shadow`，三套主题继续映射到现有高白度玻璃配方。
- 搜索框、只读结果区和选项底板等内凹区域使用 `--h5-glass-sunken` 与当前主题联动。客资列表筛选面板的选项框和日期框是局部例外，使用透明背景，仅以边框区分可点击区域。
- 顶部导航、子页面筛选导航和底部 Dock 使用独立的 `--h5-navigation-*` 变量。三套主题均保留玻璃、模糊和既有布局。
- 弹窗、抽屉和选择器保持既有浮层结构与强模糊，并使用当前主题的浮层材质。
- 长列表的每一项使用当前主题的半透明表面；均保留细边界和轻阴影，不为每项叠加 `backdrop-filter`，避免移动端滚动性能下降。
- 三套主题的可读交互色、主按钮、按压态和浅状态底均由主题变量控制；危险按钮使用系统红，禁用按钮使用系统灰，分段控件使用主题联动的浅色轨道和选中块。
- 状态标签、警告、错误、成功提示和排行榜名次等语义表面保留语义颜色，金银铜名次不改色。

## 降级与可访问性

- 浏览器不支持 `backdrop-filter` 时，导航使用 `--h5-navigation-surface-fallback`，内容使用 `--h5-content-surface-fallback` 或对应强降级变量，不得退回透明到无法阅读的表面。
- 用户启用减少透明度偏好时关闭背景模糊，并使用强降级表面。
- 新增页面应复用 `.page-container`、`.card`、`.page-list-card` 和 Vant 全局覆盖；只有页面确有独立层级时才新增局部玻璃样式。
- 标题或字段旁的问号/说明提示统一使用公共组件 `HelpPopover`：`question-o` 图标、透明圆形触发按钮（`--h5-text-secondary`，按下变主题色，触控区 ≥44px）、浅色强玻璃气泡（`--h5-glass-surface-strong` 底、`--h5-glass-border` 边、12px 圆角、悬浮阴影和强模糊），传送到 `body`。不得在各页各自实现说明气泡或使用 Vant 默认深色/白色面板，短约束提示传 `nowrap`。
- 玻璃化不得改变原有布局、点击区域、焦点状态、安全区间距和底部导航避让。
- Dock 容器通过 `.app-tabbar > .van-tabbar` 覆盖 Vant 默认定位，左右等距并包含边框宽度；移动端与桌面端均相对视口居中，避免组件样式后加载导致偏移。
- Dock 高度沿用 Vant 的 `--van-tabbar-height`，居中修复不得放大底栏高度。
- Toast 属于短暂状态反馈，不继承普通 Popup 的浅色玻璃表面；成功、失败和加载提示统一使用高对比深色背景与白色文字，确保三套主题下均可读。

## 身份头像

- 用户和客资身份头像统一使用 `SmartAvatar`；真实头像地址优先，地址缺失或加载失败时回退到 Avatar Kit v1 生成头像，不再由页面单独绘制姓名首字占位。
- 默认风格、主题和产品命名空间集中定义在 `src/config/avatar.ts`。默认使用 `geometric`，组件保留 `abstract`、`character` 和 `collection` 显式参数。
- 兼职身份使用稳定 Partner ID，客资身份使用稳定 Lead ID；租户 ID 只进入命名空间。不得使用姓名、列表下标、时间戳或随机数作为 seed，无稳定 ID 时统一使用匿名占位。
- SVG 生成由懒启动 Worker 异步执行，并通过有上限的内存缓存合并重复任务。头像容器必须在加载前固定宽高，避免生成或图片解码造成布局跳动。
- 组件统一处理真实图片地址变化和失败回退。姓名已在头像旁展示时传 `label=""`，避免读屏重复朗读；头像独立表达身份时提供明确的可访问名称。
- 圆形或圆角裁切属于展示组件职责。业务页面可保持既有边框和名次装饰，但不得修改生成器输出或为同一身份按页面切换默认风格。

## 提交客资页

- 顶部说明默认收纳在右上角 `HelpPopover`（`question-o`）的轻量提示中；页面正文不重复展示流程说明。
- 课程入口使用等宽操作卡，课程目录、来源渠道、客资分类和地区选择器统一传送到 `body`，遮罩覆盖完整视口并避开底部安全区。
- 课程目录面板的分类列表、课程列表、规格区、班型区和确认区使用透明或分层玻璃表面，并跟随当前主题。
- 单选字典面板必须展示标题、可滚动列表、当前项勾选和关闭按钮；空字典显示“暂未配置”，不得补充静态业务选项。
- 附件上传状态至少区分等待上传、上传进度、服务端处理、完成和失败；失败项保留重试，上传中支持取消，提交前只允许有效 `infraFileId`。
- 提交页底部操作栏采用轻量透明玻璃工具栏，保留安全区和底部导航避让；主操作使用实心按钮，返回操作使用描边按钮。
- 地区、来源渠道和客资分类底部面板共享轻量遮罩、顶部圆角和连续内部层，使用当前主题的半透明玻璃表面。
- 个人资料和修改密码表单采用扁平统一材质：外层卡片与字段区域使用同一背景，字段不再显示独立白色底板，仅保留必要分隔线。
- “我的”页面退出登录按钮使用当前主题色的玻璃描边样式，与个人中心卡片材质一致；退出确认仍保留语义化确认对话框。

## 客资筛选

- 客资列表筛选入口使用当前主题的内凹表面；存在已应用条件时以主题色计数标识反馈状态，不使用固定灰黑按钮。
- 客资状态（全部、待判定、有效、无效、已成交、已关闭）分段统一使用 `LiquidSegmentedControl`，与消息中心、收益中心保持一致的圆角胶囊、滑动指示块和主题联动；不再手写等分格子加竖线分隔的分段控件。
- 筛选抽屉及其选项、日期二级选择器统一传送到 `body`，复用轻量玻璃遮罩、24px 顶部圆角、连续透明内层和安全区间距。
- Vant Picker 的工具栏、滚轮底板、渐隐遮罩与选中框必须使用主题材质变量。警告信息保留语义色。

## 消息中心

- “全部、客资、反馈、提现”等服务端消息分组使用与收益中心一致的液态分段选择器，保持等宽、主题联动和移动选中块；不得在前端复制或补造消息分组。
- “只看未读”作为可与任意分组组合的独立开关放在分段选择器下方，文案与开关左对齐成一组；“全部已读”移至该行右侧、右对齐，做成主题色胶囊按钮（浅主题色底、主题色文字、细描边、全圆角，跟随主题切换，触控区不小于 44px），作为独立操作不复用分组选中样式，点击仍走确认弹窗并明确针对当前账号全部消息。

## 提现申请

- 提现项目使用整行复选交互；全选必须同步表达未选、部分选中和全部选中状态，金额与项目计数只按当前接口返回且实际选中的项目计算。
- 收款银行卡优先展示本人已保存卡片并明确默认卡；无已保存卡时直接进入新卡表单，有卡时提供清晰的新增与返回切换，不展示无效的返回入口。
- 新卡表单提供独立的“保存并使用此卡”按钮；保存成功后刷新本人银行卡并自动选中新卡。未保存的新卡仍可仅用于本次提现，不应与保存操作混用。
- “添加新卡”“返回已保存银行卡”和底部“立即申请”均使用胶囊形按钮；“立即申请”为实心主按钮，添加和返回操作使用主题描边/中性描边以区分操作层级。
- 复选框和单选框标签必须设置页面级字号与行高，不得继承 `amfe-flexible` 根字号；课程名称过长时省略，右侧金额保持完整可见。

## 银行卡管理

- 银行卡编辑、设为默认和删除操作使用卡片底部一体化等分操作栏，保持清晰分隔和至少 44px 的实际触控高度；编辑与默认操作使用主题色，删除保留危险语义色。
- 添加银行卡底部弹窗使用单层承载面，字段背景保持透明并直接透出弹窗底色，不再叠加第二层面板；底部操作必须保留安全区间距。

## 系统反馈列表

- 导航栏、搜索框、反馈类型和反馈状态筛选属于同一连续顶部表面，不分别叠加卡片边框、阴影或明显横向分割。
- 搜索输入保留 `--h5-glass-sunken` 内凹区域；类型和状态仅通过主题色文字、选中下划线和顶部区域底部的弱分割线表达层次。
- 状态筛选继续支持吸顶，吸顶后的背景、可读性和安全区间距必须与顶部连续表面一致。

## 投诉记录列表

- 导航栏和状态筛选使用 `--h5-glass-surface`，投诉记录卡片按下方主题联动规则使用 `--h5-content-surface`。
- 状态筛选保留吸顶能力，仅使用主题色选中下划线和底部弱分割线表达层次，不叠加独立白色面板。

## 我的子页面

- 主题设置、消息通知、个人信息、提现记录、银行卡管理和修改密码页面统一使用页面级 `my-subpage-page` 导航边界；导航与筛选区域使用 `--h5-navigation-*`，保留主题模糊、边缘高光和底部弱分割线。
- 普通内容卡片使用 `--h5-content-*`；表单字段、消息筛选内嵌控件、银行卡弹窗字段继续使用透明或 `--h5-glass-sunken` 内层，不叠加第二层实底。
- 消息分组筛选与未读开关作为连续吸顶玻璃表面，消息记录卡片按下方主题联动规则使用 `--h5-content-surface`；未读红点、金额、状态和删除等语义颜色保持不变。
- 主题卡片的预览必须展示对应画布、白色内容卡片和强调色。卡片普通态及选中态均使用 `--h5-content-surface`，当前项通过主题色边框和勾选区分；银行卡底部操作栏、表单主按钮和提现操作保持原有触控高度与主/危险语义。

## 首页客资统计卡片

- 卡片最小高度为 160px，统计内容区和指标按钮最小高度为 72px，标题下间距为 8px；窄屏标题与周期换行时允许卡片自然增高。
- 三项指标保持等宽，数字使用弹性列、等宽数字和独立箭头列；430px 以下数字字号为 22px，箭头为 24px，360px 以下箭头为 20px。四位数须完整显示，不得省略或与箭头重叠。

## 排行榜

- 首页简榜和详细排行榜使用同源主题玻璃表面，顶部、榜单主体和“我的排名”浮层必须提供不支持模糊及减少透明度偏好的降级材质。
- 首页简榜标题使用后端返回的排行榜类型名称并补充“榜”后缀，周期在标题右侧以主题色小标签显示：`today` 为“日榜”、`week` 为“周榜”、`month` 为“月榜”、`total` 为“总榜”；不再重复显示“本月预计收益排行”等组合副标题。点击“查看全部”时，详细排行榜必须继承首页当前类型和周期。
- 详细排行榜保留金、银、铜的名次语义颜色；其余排名、姓名、数值和追赶提示使用主题文本变量，避免在浅色玻璃表面使用固定白色正文。
- 首页简榜第 1 名与详细排行榜 Top3 使用共享 `LeaderboardCrown`，保持皇冠形状和尺寸一致；首页简榜第 1 名的行背景、头像强调和皇冠跟随当前主题色，详细排行榜 Top3 继续使用金银铜配色。排行榜数据、排序和名次计算仍由现有 API 提供。
- 排行榜底色使用 `--h5-leaderboard-surface` 和 `--h5-leaderboard-surface-strong`，主题色应比普通卡片更明显但保持浅色可读；不支持模糊时使用对应的 `--h5-leaderboard-surface-fallback`。

## 主题卡片表面复用

- 提交客资顶部卡片、消息中心概览卡片、客资工具栏、收益概览、收益分段底板和首页排行榜共享 `.hero-surface` 与内容表面变量，使用当前主题的轻渐变和玻璃表面。
- 各页面保留自身布局；收益分段底板保留胶囊圆角、选中指示器和吸顶行为。
- 收益中心在用户拥有 `zsjos:withdrawal:apply` 权限时显示与客资列表一致的右下角圆形悬浮入口；入口使用人民币钱币图标，避让底部导航和安全区，点击进入现有提现申请页，不替代顶部“立即提现”按钮。

## 收益中心

- 收益汇总中的累计收益、待结算、提现中和已提现使用 2×2 等分布局；两行间距为 8px，每个单元的金额与标签整体水平和垂直居中。
- 收益汇总、类型筛选与第一张收益明细卡片之间使用 4px 紧凑间距；后续收益明细卡片之间继续保持 12px 间距。
- 四项汇总金额的口径说明收纳在标题旁的 `HelpPopover` 中。收益中心可单独开启主题浅色底，使用少量主题主色混合强玻璃底色，气泡箭头与面板同色；其他页面的帮助气泡保持默认强玻璃底色。

## 指定内容卡片主题联动

- 收益明细卡片、客资跟进卡片、客资列表卡片、个人资料表单、银行卡列表卡片、修改密码表单，以及消息记录、提现记录、主题选择、系统反馈记录、投诉记录卡片和提交客资客户信息表单统一使用 `--h5-content-surface`，底色随珊瑚粉、天空蓝和薰衣草紫主题变化。
- 客资列表和跟进列表的同类骨架卡片沿用该变量；不支持背景模糊时变量切换为主题降级表面，减少透明度时切换为强降级表面，均保留主题联动。仅复用背景配方，不为列表项新增背景模糊。
- 表单字段与银行卡操作栏默认保持透明；圆角、阴影、排版、操作反馈及金额和状态等语义颜色保留。
- 范围不包含导航、顶部概览、筛选栏、空态卡片、详情弹窗、银行卡新增弹窗或银行卡编辑表单。
