# 兼职端登录页

- 账号、密码输入区上方不再显示登录/激活切换按钮。
- 输入区下方的「登录」「企业微信登录」等宽并排；下方显示「首次使用？激活账号」及协议勾选项。
- 激活入口切换到原手机号、新密码、确认密码、邀请码表单，继续使用 `useAuth.activateWithInvite` → `POST /zsjos/auth/activate`，成功后沿用原登录态和跳转流程。激活表单下方可返回登录。
- 协议勾选默认未选中，仅保留当前页面的选择状态；本次未新增登录、激活或企业微信授权拦截规则。
- 仓库暂无正式《用户协议》《隐私政策》页面；入口暂提示未配置，待提供正式链接或正文后接入，不编造法律文本。
