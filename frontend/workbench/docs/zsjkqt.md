# 中世健考勤通原生迁入约定

考勤通由 HRM 菜单进入，路由为 `/hrm/zsjkqt`。服务端菜单使用既有 `zsjos-workbench` 工作台专用组件标记，Vue Admin 按现有过滤规则排除该页面，React 根据路径渲染。页面在 React 工作台内原生渲染，保留原桌面应用的首页、参数设置、员工确认卡片、每日编辑、汇总区和部门时段设置。新增草稿箱及保存提示用于系统内持久化。

## 目录与运行边界

| 位置 | 职责 |
| --- | --- |
| `src/features/zsjkqt/core/` | 原 TypeScript 业务模型、计算规则、恢复逻辑及对应测试 |
| `src/features/zsjkqt/ui/App.tsx` | 原界面和操作流程的网页适配 |
| `src/features/zsjkqt/ui/icons.tsx` | 保留原图标几何，附原许可；不增加图标运行库 |
| `src/features/zsjkqt/styles/zsjkqt.css` | 考勤通独立样式作用域 |
| `src/features/zsjkqt/ZsjkqtPage.tsx` | 草稿箱、授权入口、保存状态与编辑器装配 |
| `src/features/zsjkqt/draftSession.ts` | 单草稿串行保存及版本状态 |
| `src/services/zsjkqt.ts` | 类型化请求，复用 Workbench 认证、租户和错误处理 |

Excel 上传、解析和导出由 Java 后端执行。产品页面不依赖 Tauri、Rust、ExcelJS 或原项目目录。原桌面测试中的 ExcelJS 部分只作为不可修改的归档保留，其执行场景移植到 Java 测试；不新增 npm 依赖。

## 明确限定的界面例外

用户明确要求保留原应用界面。因此原考勤编辑器保留自身视觉和控件布局，不机械替换为工作台通用业务页面。这个例外只适用于 `features/zsjkqt` 的原编辑器；新增草稿箱使用既有 `BusinessTable`，其他工作台页面继续遵循原规范。

全部原全局选择器（包括 `body`、`:root`、按钮、表单控件及媒体查询）须限定到 `.zsjkqt-root`；外层 `.zsjkqt-viewport` 承担应用内容滚动。原编辑器最小宽度为 1160px，窄屏通过应用内部横向滚动访问，不能把整个平台撑宽，也不能把原桌面布局改成另一套界面。弹层、详情提示和操作底栏均应在对应宽度的实际浏览器中检查。

Java 包/类、数据库表、API、权限、路由与样式边界使用 `zsjkqt` 命名空间。模块内函数局部变量沿用原名，以减少纯命名改动对公式核验的干扰。原考勤状态字符串属于保留的引擎协议，不引入新的管理员选项列表。

## 数据及交互约定

- `zsjos:zsjkqt:access` 控制整个应用。前端根据服务端权限显示入口，后端仍独立鉴权；不推断角色名。
- 获授权用户共享本租户所有草稿和内部配置。创建者、修改者用于审计，不限制谁可以继续编辑。
- 同月允许多个草稿；重复文件提示继续原草稿或新建副本，不能默默覆盖。
- 草稿保存源事实、月度参数、每日修订、汇总覆盖及确认状态，同时恢复续改参数候选、当前员工、筛选和搜索。`personnelProfiles` 快照保留参数阶段使用的人员修订输入；公共资料后续变更只供新导入使用，不改变旧草稿恢复结果。打开草稿恢复保存状态，不能用当前配置重算后冒充恢复结果。
- 自动保存与“保存并下一个”共用串行写入及版本控制。失败保留本地修改并显示可重试状态；确认保存成功后再切换员工。
- 导出使用已保存的匹配版本。导出后仍可编辑，导入正式汇总表续改建立独立草稿。
- 部门时段设置保留原计算影响和显式保存入口。人员资料与 HRM 员工、部门无关联；旧人员资料和旧草稿不导入。

接口、错误和数据库边界见 [API 契约](../../../docs/api/zsjkqt.md)。全量原测试对应关系及运行命令见 [测试迁移清单](../../../docs/testing/zsjkqt/README.md)。


## 工作台高度适配（2026-10-23）

按用户本次界面调整要求，移除原编辑器顶部重复标题、网页版标识及大块说明卡片；确认进度和异常总数放在保存工具栏右侧。错误、配置校验与操作结果仍以紧凑状态行显示，避免隐藏失败反馈。

编辑器按工作台内容区域的实际可见高度布局，观察宿主尺寸及窗口调整，不再将浏览器完整高度重复加到三个面板上。员工确认阶段保持三列，人员、日历和汇总分别在内部滚动；底部返回、确认、导出操作占用独立固定空间。原最小阅读宽度和窄屏内部横向滚动保留，页面不扩张工作台外层。月度参数的两列/窄屏堆叠以及首页休息日导入继续沿用既有行为。

本次只改变显示布局；确认/异常计数来源、选项、权限、请求、草稿保存和考勤计算均沿用原实现。

较窄桌面列中，日期详情按钮不换行，状态文本及汇总输入保持完整可见。日期详情复用既有 Ant Design Popover 渲染到独立浮层，并保留考勤通自身内容和样式，避免固定高度日历滚动区裁切原始明细。
