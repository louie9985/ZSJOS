# 订单管理与成交订单审批详情展示

订单管理 `MySalesOrderPage` 与成交订单审批 `SalesOrderApprovalPage` 的详情主区采用连续信息表：订单概览、学员资料、成交与付款依次通栏展示，每组使用浅底字段名与左对齐值；取消逐字段圆角、间距和阴影。桌面每行两项，主区不足 620px 时每行一项，最后单项及长字段通栏。审批页的待审与已处理任务共用此布局，已处理任务继续展示处理结果、处理时间与审批意见。

订单类型、班种、课程类别及已记录的分类字段使用 Ant Design 浅色标签；状态沿用现有状态颜色与名称，审批轮次和“历史未记录”使用中性标签。所有字典字段继续显示原有快照标签，不查询当前字典替换历史值。姓名、编号、时间、联系方式和金额保留原始显示语义。

成交课程继续使用 BusinessTable，备注、服务与缴费凭证保留完整内容和预览操作。左侧列表、顶部信息、客户档案及右侧审批流程与操作保持原有逻辑。主管确认、业绩明细等其他消费者不传 `informationLayout="table"`，继续使用原展示。审批按钮仍遵循原有任务权限和生命周期约束，布局不改变任何审批行为。

订单管理与成交订单审批的缴费凭证复用通用 `AttachmentCard`，显示文件名称、类型、大小及预览/下载入口。初次显示使用已授权的详情数据；预览、下载和失败重试重新通过所在页面的订单详情接口取得最新凭证地址：订单管理使用 `managementSalesOrder`，审批使用 `salesOrder`。不转用上传接口或猜测文件权限；无凭证保持空状态，无地址或刷新后已不可访问显示明确错误并允许重试。切换订单时重建附件卡片，避免旧附件预览及加载结果串单。其他详情消费者未提供 `reloadVouchers` 时继续使用原凭证展示。
