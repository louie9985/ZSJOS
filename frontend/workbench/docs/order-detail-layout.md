# 订单管理详情展示

订单管理 `MySalesOrderPage` 的详情主区采用连续信息表：订单概览、学员资料、成交与付款依次通栏展示，每组使用浅底字段名与左对齐值；取消逐字段圆角、间距和阴影。桌面每行两项，主区不足 620px 时每行一项，最后单项及长字段通栏。

订单类型、班种、课程类别及已记录的分类字段使用 Ant Design 浅色标签；状态沿用现有状态颜色与名称，审批轮次和“历史未记录”使用中性标签。所有字典字段继续显示原有快照标签，不查询当前字典替换历史值。姓名、编号、时间、联系方式和金额保留原始显示语义。

成交课程继续使用 BusinessTable，备注、服务与缴费凭证保留完整内容和预览操作。左侧列表、顶部信息、客户档案及右侧审批流程与操作保持原有逻辑。其他审批、主管确认、业绩明细等消费者不传 `informationLayout="table"`，继续使用原展示。
