# 中世健客资主从视图排序与数量

主从视图使用常驻“排序字段”和“排序方向”选择器，支持最近活动时间、更新时间、提交时间和客资编号。选字段后可切换升序或降序；选回默认排序时清除显式排序参数并禁用方向选择。默认待办优先规则及下属销售按提交时间排序的规则保持不变。

排序仍通过既有列表接口传递 `sortField` / `sortOrder`，不是对已加载一页作本地排序。切换排序清理批量勾选并沿用页面重新查询逻辑。表格模式切换过来的其他排序字段保留，显示为“当前表格排序字段”。

搜索与筛选按钮固定在第一行，已选条件独立换行，排序和数量各占完整一行。顶部“当前结果”采用当前查询接口返回的 `total`，“已加载”采用已加载记录数；包括零结果。首次查询/刷新显示统计中，失败或无权限时不显示旧数量。折叠头像列表时隐藏扩展工具栏。

以上适用于复用客资管理页的主从视图。没有新增接口、权限、字典或业务数据。独立设计预览位于 `test/lead-sort-preview.html`，仅使用示例数据。

显式选择排序字段和方向时，前后端均取消待处理任务优先，以服务端分页前排序为准；清除排序恢复默认规则。表格模式通过定位链接打开详情时，详情独立加载，不插入或保留到当前分页数据中；接单刷新也不向表格页额外插入记录。
