# 我的学员筛选

`/zsjos/my-students` 表格模式将排序、学习规划师、接收状态、交付阶段、任务状态、班级、服务状态、搜索和高级筛选集中在 BusinessTable 工具栏，按可用宽度换行，不再在标题与表格之间另放快捷筛选行。

表格与收件箱复用同一份筛选控件和状态。收件箱筛选位于左侧列表顶部，展开时按两列排列；折叠时仍保留条件，快捷筛选生效后搜索入口高亮。每个快捷筛选只出现一次，搜索与高级筛选入口各保留一个。高级筛选继续支持原有字段与组合条件、模板和生效条件标签。

选项继续来自现有筛选目录和班级 API，筛选参数及权限保持现有契约。改变条件回到第一页并清理旧详情；选项加载失败提供重试。

班级下拉面板独立于输入框加宽，最大不超过视口可用宽度；长班级名称和考期快照完整换行显示，采用非虚拟列表适配可变行高。已选名称保留原生完整文字提示。

学习规划师等快捷筛选与高级筛选中的动态选项使用[统一筛选显示规则](filter-select-display.md)，长名称完整换行，筛选功能与参数不变。
