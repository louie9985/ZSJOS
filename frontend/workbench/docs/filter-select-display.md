# 筛选下拉完整显示

工作台的动态名称筛选统一使用 `components/filterSelectDisplay.tsx` 的 `filterSelectDisplayProps`，放在 Select 的既有属性之后；已有专用选中文字渲染可保留在其后。下拉面板优先宽 480px，最大为视口减 24px，并允许横向平移以适配靠近屏幕边缘的控件；选项及分组名称完整换行，关闭固定行高虚拟列表以容纳多行。输入框保持原宽度与单行布局，选中文字提供完整 title 提示，多选同样适用；素材库适配筛选保留既有的选中文字多行展示。

覆盖共用高级筛选的字段、选项值、时间字段与模板；学员快捷筛选；班级项目/班主任；素材库适配条件与类型、素材选择及定位卡素材筛选；内容审核人员/平台；媒体日历；销售及交付业绩明细；指定人员、公告统计部门、跟进方式/结果、计划类型、新媒体中心、通知业务场景与提现状态。我的学员班级下拉沿用已有的等效完整显示处理。

本次只调整显示属性。保留选项来源、标签内容、搜索、选择、多选、清空、条件组合、模板、分页、请求参数和权限。固定短选项无需强制套用；录入表单、课程选择、分班转班、TreeSelect/Cascader 和 Vue 管理端/H5 不属于本次筛选显示范围。

长人员名不撑宽筛选容器及其 Space 包装；高级筛选生效条件标签允许换行，避免选择长名称后页面横向溢出。标签原文和条件含义保持不变。

非虚拟列表会渲染当前加载的全部选项，适用于现有筛选候选集；不改变远程搜索及后端分页。已有业务控件不得因复用展示规则而替换其业务回调。
