# 返现与提现表格展示

返现表格的自定义渲染从记录字段读取原始值。ProTable `render` 的首个参数是展示节点，不用于金额运算、状态匹配或时间解析。

返现基数、金额和提现申请金额使用有限数值格式化；零显示 `¥0.00`，缺失或无效值显示 `-`，不以零掩盖异常。比例读取 `rateSnapshot` 并转为百分数，时间遵循现有北京时间格式化契约。产品继续展示 `productNameSnapshot`，客资编号继续使用 `leadNo`。

当前返现响应仅提供内部 `orderId`，该列标为“内部订单ID”；提现响应仅提供 `applicantUserId`，该列标为“申请人用户ID”。这些字段不冒充业务订单号或申请人姓名，也不以收款账户名推断申请人。未来展示业务订单号、申请人姓名时需由授权后端接口提供对应字段。
