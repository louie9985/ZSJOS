# 学员管理筛选（2026-10-28）
学习规划师候选使用系统 study_planner 角色的启用成员与既有可见用户范围交集，角色缺失或禁用时返回空选项，不改变学员数据授权。
表格模式移除独立排序菜单，保留列头排序；列表模式保留排序菜单。移除旧“全部服务状态”快捷筛选，不改变服务生命周期规则和其他接口兼容字段。
批注 serviceNeeded 的最终展示采用下文“无需服务”勾选交互，存储值及快照不迁移。新增 proxyStudent（是否为代理）与 serviceNeeded 快捷筛选，选项来源 infra_boolean_string；需要批注 read 权限。服务端在分页前按相同租户、未删除的同一服务批注匹配，两项条件取 AND；未标注、无批注行按非代理（proxyStudent=false）且需要服务（serviceNeeded=true）处理。清除选项即取消该条件。

## 批注勾选交互（后续确认）
代理学员与无需服务均使用复选框，默认不勾选。代理学员勾选对应 proxyStudent=true，取消时清空代理人；代理人必填规则保留。无需服务勾选对应 serviceNeeded=false，取消对应 true；旧字段含义不反转。未标注数据在界面与筛选中均默认为非代理且需要服务，读取不写入，编辑保存时应用默认值。既有字典校验与标签快照继续保留；只读状态使用禁用复选框。快捷筛选仍按原正向“是否需要督学”查询批注值及上述默认值，未标注数据不自动回填。

现有关键词搜索同时匹配同一课程服务批注的代理人姓名（模糊匹配）；仅有批注读取权限时启用该匹配项，同租户且未删除，不扩大学员可见范围。不增加接口参数，原有姓名、编号及联系方式搜索保留。
