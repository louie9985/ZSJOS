# 返现两级页签

员工工作台的返现管理和我的返现共用 CashbackPage。一级卡片页签展示返现类型，二级小尺寸页签展示返现状态；两级首项均为“全部”，初始均选中全部。选项、名称和顺序沿用服务端 cashback 筛选目录。

点击任一级立即查询并回到第一页，保留另一维度、已提交关键词和高级筛选；选择全部仅移除对应 type 或 status 条件。所有筛选取交集，保留请求去重和旧响应保护。选项目录加载中或失败时禁用页签，失败提供重试；无查询权限不请求数据或目录。详情和业务操作沿用既有权限。

验证：npm run typecheck；已有 Workbench Vite 服务运行时执行 python test/cashback-tabs-browser.py。测试页面使用隔离合成数据，不写入真实业务数据。

返现列表表头、返现详情、关联提现审核列表表头及详情统一使用“兼职”，均展示服务端 partnerName，数据含义保持不变。复用返现详情的入口沿用相同标签；通过／驳回审核弹窗不单独展示该字段。
