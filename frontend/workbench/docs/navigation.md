# 导航

导航完全来自权限接口的 `menus` 树。React 保留后端名称、顺序、显隐、图标和层级语义，仅规范化父子路径；布局模式按自身交互展示完整的递归菜单层级。

Workbench 支持五种布局：左双列、顶+左、纯顶栏、左单列、Mini 浮层。左双列和顶+左保留一级入口与二级目录侧栏；纯顶栏将递归目录放入顶部下拉菜单；左单列使用可展开/收起的目录树；Mini 浮层使用图标栏和悬浮目录。布局设置只改变呈现方式，不改变服务端菜单、权限或路由身份。

前端不得根据角色名、部门名、岗位名或 demo 路由补充菜单。直接访问路径也必须能够在授权菜单中反向定位；仅隐藏导航项不构成授权。移动端可以使用抽屉，但仍保留服务端递归层级。

React 只使用本地组件注册表或统一安全占位页，不执行后端传入的组件路径。外部链接可以按明确交互打开，但不能成为未经确认的默认落点。

外框架头部不再提供未接入业务的全局搜索占位。具备接单权限且后端确认销售专员资格时，原位置显示固定尺寸的“接单开启/暂停、页面活跃/离线、开启/暂停接单”三段式控件；其他账号不显示该控件。
