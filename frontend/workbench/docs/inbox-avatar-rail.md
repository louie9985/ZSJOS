# 众视界工作台头像列表

客资管理与我的学员的左右分栏模式支持完整列表和头像栏切换，首次展开，各自在当前浏览器记住状态。表格模式不展示此入口。媒体学员页保持已有相同交互。

收起态顶部展开与筛选使用同排轻量图标按钮，默认无独立边框，已筛选时突出筛选入口。桌面收起为 72px；≤768px 收起为横向滚动头像条。客资手机详情继续使用原有抽屉；我的学员收起时下方显示详情。头像支持选中态及键盘/悬停姓名与业务编号提示，客资展示 leadNo，学员展示 personNo；未记录时不回退内部 ID。新客资保留红点及可访问提示。

展开态主工具栏由收起按钮、可压缩搜索框、筛选按钮和排序按钮组成单行；按实际滚动条宽度预留右侧空间，使操作区与卡片对齐。客资默认按最近活动时间倒序（并列时按内部 ID 倒序）展示，也可选择最近活动、更新时间、提交时间或客资编号及方向。我的学员的班级与服务状态选择器并排放在第二行。

搜索与筛选图标展开原筛选区并聚焦搜索框；关键词、班级、服务状态和高级条件均保留，已应用筛选时高亮入口。收起和展开不重建详情或清空草稿，分别保留两种形态的滚动位置。布局偏好存储不可用不影响当前页面切换。

客资沿用滚动加载更多，手机横向滚到末尾也可继续加载，错误可展开查看或重试；我的学员使用上一页/页码/下一页。窄栏适配加载、空状态与错误提示。切换不主动刷新业务数据；滚动加载仍可因末尾进入可视区而触发。

实现复用工作台内部 InboxAvatarRail 控件与状态 hook，不新增跨项目包或依赖，也不修改数据源、权限及后端接口。

验收入口：`test/inbox-avatar-rail.html`（隔离测试传输，不写入实际业务数据）；Python 浏览器验收脚本与其同目录。

以上班级/服务状态和页码说明属于规划师学员列表。编导/运营「我的学员」使用 `media_student/media_students` 独立目录：左栏工具行是收起按钮、缩短的弹性搜索框和筛选按钮，按真实滚动条宽度与卡片边缘对齐；关键词提示保持“搜索姓名或手机号”。责任运营、平台、账号状态在统一抽屉中组合，应用后重置滚动分页；顶部服务期页签保持独立并与条件相交。
